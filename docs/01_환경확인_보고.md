> **먼저 알려 드릴 점**: 이번 확인은 사용자의 개인 컴퓨터가 아니라, 이 대화가 실행되는 **클라우드 작업 환경(원격 컨테이너)** 에서 했습니다. 작업 지시서의 "이 컴퓨터"가 사용자의 컴퓨터를 뜻한다면, 아래 결과 중 버전과 설치 여부는 사용자의 컴퓨터에서 다시 확인해야 합니다.

## 2. Higgsfield 사용 가능 여부

- 이 대화의 Claude Code에는 Higgsfield MCP(외부 도구 연결 규격) 커넥터가 연결되어 있습니다. `generate_video`, `generate_image`, `models_explore`, `jobs_wait` 등의 도구가 보입니다.
- 크레딧을 쓰지 않는 `balance` 도구로 계정을 조회했습니다. 결과는 **잔여 크레딧 10.01, 요금제 plus**입니다.
- **확인하지 못한 점**: 서버가 Claude Code를 비대화형(`claude -p`)으로 따로 실행할 때도 이 커넥터가 그대로 붙는지는 아직 시험하지 않았습니다. 3단계에서 확인합니다.
- **주의**: 잔여 10.01 크레딧은 시안 영상 한두 개 분량에 그칠 수 있습니다. 5단계 전에 충전 여부를 정해야 합니다.

## 4. 훅 이벤트와 서브에이전트 시작·종료 감지 (공식 문서 code.claude.com/docs/en/hooks 기준)

- **서브에이전트 시작**: `SubagentStart` — 입력에 `agent_id`, `agent_type`(직원 이름)이 들어옵니다.
- **서브에이전트 종료**: `SubagentStop` — `agent_id`, `agent_type`, `agent_transcript_path`, `last_assistant_message`(최종 응답 글)가 들어옵니다.
- **도구 사용**: `PreToolUse`(실행 전, 막을 수 있음), `PostToolUse`(실행 후, `tool_name`, `tool_input`, `tool_response`, `duration_ms`), `PostToolUseFailure`(실패). 서브에이전트 안에서 일어난 호출에는 `agent_id`, `agent_type`이 함께 붙어 **어느 직원이 어떤 도구를 썼는지** 알 수 있습니다. MCP 도구에는 `mcp_server`도 붙습니다.
- **전체 흐름**: `SessionStart`, `UserPromptSubmit`, `Stop`, `StopFailure`, `SessionEnd` 등.
- **서버로 보내는 방법**: 훅 종류 `"type": "http"`를 쓰면 이벤트 JSON을 지정한 주소로 바로 POST합니다. 별도 스크립트가 필요 없습니다.
- **승인 흐름에 쓸 수 있는 것**: `PreToolUse` 훅이 Higgsfield 생성 도구 호출을 막을 수 있고, 비대화형(`-p`) 실행에서는 `"defer"` 결정으로 호출을 보류할 수 있다고 문서에 나옵니다. 3·5단계에서 실제로 시험한 뒤 방식을 정합니다.
- 문서에 실린 이벤트는 모두 33개이며, 위에 적은 것만 이번 작업에 씁니다.

## 사용자에게 여쭐 것

1. **실행 장소**: 스튜디오(로컬 서버 + 3D 화면)를 사용자의 컴퓨터에서 돌리실 예정입니까, 아니면 이 클라우드 환경에서 만들고 시험한 뒤 옮기실 예정입니까? 사용자의 컴퓨터라면 그곳에서 `node -v`, `claude --version`의 결과와 Higgsfield 커넥터 연결 여부를 알려 주십시오.
2. **크레딧**: 잔여 10.01 크레딧으로 5단계 시험(싼 시안 하나)을 진행해도 되겠습니까?
3. **인물 자료**: 유우, 튤리, 노이, 브로의 기존 마스터 시트나 시리즈 기록이 있다면 어디에 있는지 알려 주십시오. 캐릭터 담당이 새로 만들지 않고 물려받게 하기 위해서입니다.
4. **ASIDE**: 배급 단계에서 ASIDE를 쓰려면 설치 방법이나 도움말 출력을 나중에 전달해 주십시오.

위 내용을 승인해 주시면 2단계(폴더 구조, 직원 설정, 업무 파일)로 넘어가겠습니다.
