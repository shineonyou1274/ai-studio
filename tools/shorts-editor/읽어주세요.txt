쇼츠 편집기
===========
폴더에 넣은 영상·사진을 세로 쇼츠 한 편(약 10초)으로 이어 붙여 줍니다.
여행, 맛집, 일상 브이로그, 매장·병원 홍보처럼 찍어 둔 장면을 이어 붙이는 영상용입니다.

들어 있는 것
  make_shorts.py   편집기 본체
  settings.json    주제, 제목 문구, 컷 길이, 장면 글자 설정
  videos/          영상·사진을 넣는 곳
  sfx/             도입부 효과음 3개(직접 합성한 소리라 저작권 걱정 없이 쓸 수 있습니다)

쓰는 법 (자세한 설명은 가이드 문서를 보세요)
  1. videos 폴더에 영상을 넣습니다.
  2. settings.json 의 주제와 제목을 바꿉니다.
  3. Claude Code 에서 이 폴더를 열고 "make_shorts.py 실행해 줘" 라고 합니다.
  4. output/shorts.mp4 가 완성본입니다.

주제 (settings.json 의 "주제")
  여행   DAY 1, DAY 2 + 핀과 장소 이름
  맛집   핀과 가게·메뉴 이름
  일상   촬영 시각(오전 7시) + 한 줄
  홍보   번호(01, 02) + 한 줄
  없음   제목만

알아 두실 것
  - 윈도우에서 만들고 확인했습니다. 맥에서는 확인하지 못했습니다.
  - 파이썬, Pillow, ffmpeg 가 필요합니다. Claude Code 에게 설치를 부탁하면 됩니다.
  - 음악은 들어 있지 않습니다. 올릴 때 인스타·유튜브 앱에서 고르세요.
  - 장면 글자를 AI 가 추정해서 넣으면 틀릴 수 있습니다. 올리기 전에 꼭 확인하세요.
  - 카메라를 보고 말하는 영상에는 맞지 않습니다.
  - 제목 글꼴은 컴퓨터에 있는 맑은 고딕을 씁니다. 다른 글꼴을 쓰려면 fonts 폴더를 만들어
    굵은 한글 글꼴 파일(ttf·otf)을 하나 넣으면 그 글꼴로 바뀝니다.
