# 쇼츠 편집기

## 출처
- 원본: 하랑 「쇼츠 편집기 만들기」 무료 가이드 — https://harang-shorts-editor.vercel.app/
- 사이트에 "이 자료는 무료로 나눕니다"라고 적혀 있고, 6장 「내 스타일로 바꾸기」에서 고쳐 쓰도록 안내합니다.
- `sfx/`, `읽어주세요.txt`는 받은 그대로이고, `make_shorts.py`와 `settings.json`은 아래 「바꾼 점」을 더했습니다.

## 빠른 사용법
1. `videos` 폴더에 영상(mp4·mov)과 사진(jpg·png)을 넣습니다.
2. `settings.json`에서 주제와 제목을 바꿉니다.
3. Claude Code에서 이 폴더를 열고 "make_shorts.py 실행해 줘"라고 합니다.
4. `output/shorts.mp4`가 완성본입니다.

내 영상과 결과물(`videos`, `music`, `motion`, `output`)은 저장소에 올라가지 않게 해 두었습니다.

## 바꾼 점

### 화면 비율
`"화면비율"`을 바꿉니다.

| 값 | 크기 | 쓰는 곳 |
|---|---|---|
| `"9:16"` | 1080×1920 | 쇼츠, 릴스, 틱톡 (기본) |
| `"16:9"` | 1920×1080 | 유튜브 일반 영상, 공모전 |
| `"1:1"` | 1080×1080 | 인스타 피드 |
| `"4:5"` | 1080×1350 | 인스타 피드, 스레드 |

### 길이
`"최대길이"`(초)를 늘리면 1~3분 영상도 만듭니다. 긴 영상은 `"컷길이"`를 1~2초로 늘리는 편이 보기 좋습니다.
영상이 짧거나 적으면 쓸 장면이 모자라 더 짧게 나오고, 그때는 안내 문구가 나옵니다.

### 장면 직접 고르기
`"장면"`에 쓸 구간을 순서대로 적으면 자동으로 고르지 않고 그 구간만 씁니다. 장면마다 길이가 달라도 됩니다.

```json
"장면": [
  {"파일": "clip1", "시작": 0.5, "끝": 2.5, "글자": "아침 시장"},
  {"파일": "clip3", "시작": 5, "끝": 9, "글자": "골목길", "효과음": "whoosh"},
  {"파일": "photo2", "길이": 2}
]
```
- `"파일"`: 파일 이름의 일부
- `"시작"`·`"끝"`: 영상에서 쓸 구간(초). 사진은 `"길이"`(초)
- `"글자"`: 왼쪽 아래에 붙을 한 줄(선택)
- `"효과음"`: 장면이 시작할 때 낼 소리(선택). `click`·`whoosh`·`pop` 또는 `sfx` 폴더에 넣은 파일 이름
- `"확대"`: 1.3처럼 적으면 확대해서 보여 줌(선택)

`"장면"`을 `[]`로 비우면 원래처럼 자동으로 고릅니다.

### 글자 효과
- `"제목효과"`: `"팝"`(튀어나옴, 기본) · `"슬라이드"`(위에서 내려옴) · `"펼치기"`(왼쪽부터 드러남) · `"없음"`
- `"제목시작"`: 제목이 나오는 시각(초)
- `"글자효과"`: `"슬라이드"`(장면 글자가 왼쪽에서 밀려 들어옴, 기본) · `"없음"`

### 효과음
`"효과음": true`이면 도입부 소리에 더해, 제목이 나올 때(팝이면 '뽁', 나머지는 '휙')와
장면 글자가 나올 때('딸깍') 소리가 납니다. 장면 글자 소리만 끄려면 `"글자효과음": false`.

### 배경음악
`music` 폴더에 음악 파일을 넣으면 들어갑니다. 노래가 짧으면 반복하고 앞뒤로 소리를 부드럽게 줄입니다.
- `"배경음악"`: 비우면 `music` 폴더의 첫 파일, 파일 이름을 적으면 그 파일, `"없음"`이면 끔
- `"음악크기"`: dB. 기본 -8, 0이 원래 크기
- `"음악시작"`: 노래의 몇 초부터 쓸지

### 오프닝·엔딩 (Claude Motion 등)
`motion` 폴더에 영상을 넣고 `"앞영상"`·`"뒤영상"`에 파일 이름을 적으면 맨 앞·맨 뒤에 붙습니다.
Claude Motion으로 만든 제목 영상이나 엔딩 카드를 내려받아 넣으면 됩니다.
비율이 달라도 자르지 않고 가운데에 맞춥니다. 영상의 소리도 함께 들어갑니다.
