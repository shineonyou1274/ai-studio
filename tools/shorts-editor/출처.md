# 쇼츠 편집기 출처

- 원본: 하랑 「쇼츠 편집기 만들기」 무료 가이드 — https://harang-shorts-editor.vercel.app/
- 이 폴더의 `make_shorts.py`, `settings.json`, `sfx/`, `읽어주세요.txt`는 위 사이트에서 내려받은 그대로입니다.
- 자세한 사용법은 위 사이트와 `읽어주세요.txt`를 보세요.

## 빠른 사용법
1. `videos` 폴더에 영상(mp4·mov)과 사진(jpg·png)을 넣습니다.
2. `settings.json`에서 주제와 제목을 바꿉니다.
3. Claude Code에서 이 폴더를 열고 "make_shorts.py 실행해 줘"라고 합니다.
4. `output/shorts.mp4`가 완성본입니다.

내 영상과 결과물(`videos`, `output`)은 저장소에 올라가지 않게 해 두었습니다.
