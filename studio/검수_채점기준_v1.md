# 결과물 채점·검수 기준 v1 (2026-11-14 초안)

사장님(11/14): "결과물을 채점하고 검수하는 기준을 세워 보고 따로 서브에이전트를 돌리자. 지금까지의 결과를 바탕으로, 체크리스트와 함께."

- **근거:** 사장님 지적(`feedback.md`), 제미나이 검수(교사X 2화 v3A, 소울체인지 10~12화), `series/teacher-x/실수_기록_재발방지.md`.
- **쓰는 곳:** 채점팀(`.claude/agents/scoring-team.md`)이 편집본마다 이 기준으로 점수를 매긴다. 만든 사람(편집장)과 다른 눈으로 본다.
- **순서:** 채점팀 → 고침 → 제미나이 검수 → 사장님 청취.

## 2. 점수표 (100점)
영역마다 만점에서 깎는다: **상 −8, 중 −4, 하 −1**. 영역 점수는 0점 아래로 내려가지 않는다.

| 영역 | 만점 | 무엇을 보나 (지금까지 실제로 나온 지적) |
|---|---|---|
| A 첫 3초 | 15 | 첫 화면 인물이 들리는 목소리의 주인인가 · 훅 자막이 2줄 안이고 폰에서 읽히는가 · 3초 안에 갈등이 보이는가 |
| B 처음 보는 사람의 이해 | 15 | 블라인드 판정(설명 없이 프레임+받아쓰기만) · 누가/언제/어디가 보이는가 · 낯선 말(에듀파인·기안·학맞통)에 풀이가 있는가 · 속마음과 육성이 구분되는가 |
| C 인물 정체성·몸 | 15 | 얼굴·옷·소품이 캐릭터 시트와 같은가(소매 색, 시계, 넥타이) · 손이 그 인물 손인가(성별·나이) · 뒤 인물 복제 · 화면 속 엉뚱한 글자 |
| D 입과 목소리 | 15 | 말하는 얼굴은 목소리가 나는 동안만 보이는가 · 말 안 하는 사람이 입을 움직이지 않는가 · 남의 대사 위에 '말하는 동작'(귓속말·입 가림)이 없는가 · 목소리가 그 인물 것인가 · 이름·핵심 낱말 발음 |
| E 리듬·화면 | 15 | 같은 화면이 3초를 넘지 않는가 · 정지 그림 확대가 글자 카드·소품 외에 없는가 · 교차 화면이 대사 내용과 관련된 움직이는 영상인가 · 한 장면에 같은 반응 화면을 두 번 쓰지 않았는가 |
| F 연속성 | 10 | 시간대와 빛(벽시계·창밖·노을)이 장면 시각과 맞는가 · 장소·소품·동선(일어섰다 앉음) · 다시 쓴 화면이 새 자리의 시간·인물 관계와 맞는가 |
| G 소리 | 10 | −14 LUFS, 트루피크 −1 dB 아래 · 대사 끝이 잘리거나 씹히지 않았는가 · 꼭 들려야 할 효과음이 묻히지 않았는가 · 합성 잡음·'툭' 같은 가짜 소리가 없는가 · 음악이 칼같이 끊기거나 같은 곡이 다시 시작하지 않는가 |
| H 화면 글자·자막 | 10 | `제작_매뉴얼_v1.md` 7절 자막 규칙: 한 줄만(14자 안팎) · 안전 영역(아래 23%, 오른쪽 버튼 자리 비움) · 핵심어 강조 1개 · 인물 색 · 속마음 글꼴 구분 · 덮어쓰기(\\fs 등)가 실제로 적용됐는가(sub.ass 확인) · 폰 크기에서 읽히는가 · 오래 떠 있어야 할 글자가 너무 짧지 않은가 · 오타 · 비스듬한 화면에 얹은 글자가 원근에 맞는가 · 글자끼리·얼굴과 겹치지 않는가 |

**판정**
- **90점 이상 + 관문 통과:** 업로드 가능
- **80~89점, 또는 '상'이 하나라도 있음:** 수정 뒤 업로드. '상'이 남아 있으면 점수와 상관없이 79점으로 묶는다.
- **80점 아래, 또는 관문에 걸림:** 재작업

## 3. 증거 규칙 (채점팀이 반드시 지킬 것)
- 점수마다 **증거**(타임코드, 프레임 파일, 측정값)를 붙인다. 증거 없는 '문제없음'은 '확인 필요'로 적는다.
- 프레임은 **0.5초 간격 전체 시트**와 **실제 크기 한 프레임**으로 본다. 축소 화면만 보고 판정하지 않는다.
- 소리는 측정으로만 판정한다(ebur128, silencedetect, 받아쓰기, RMS).
  - 듣고만 알 수 있는 것(속마음 울림이 충분한가, 효과음이 어색한가)은 **'사장님 청취 필요'**로 남긴다. 통과로 치지 않는다.
- 지난 검수(`06_검수/gemini_검수.md`, 지난 채점표)의 지적이 고쳐졌는지 먼저 하나씩 본다: 해결 / 덜 됨 / 새 문제.

## 4. 단계별 체크리스트 (만드는 사람이 넘기기 전에 스스로)

### 대본
- [ ] 사장님이 말하지 않은 설정을 넣지 않았다(필요하면 '제안'으로 따로)
- [ ] 줄마다 말하는 사람 → 듣는 사람이 적혀 있다
- [ ] 처음부터 끝까지 시각·장소·말하는 사람을 다시 읽었다(고친 곳만 보지 않음)
- [ ] 낯선 말은 화면 풀이를 넣을 자리를 정했다
- [ ] 소리 내어 읽었다. 직함 뒤 쉼표가 없다

### 녹음
- [ ] 받아쓰기로 확정 대사와 한 글자씩 맞췄다(반복·군더더기 없음)
- [ ] 이름·핵심 낱말 발음을 받아쓰기로 확인했다
- [ ] 쉼 줄이기 뒤 문장 사이 쉼이 0.25초 아래로 줄지 않았다(silencedetect)
- [ ] 자른 자리가 소리 크기(RMS) 쉼 안에 있다
- [ ] 속마음 줄에 울림 처리를 했다

### 그림·영상 생성
- [ ] 비용을 보여 주고 승인받았다. 잔액·최근 사용은 `balance`·`transactions`로 확인했다
- [ ] 요청에 든 ID는 모두 파일에서 grep으로 전체 확인했다. 미완성 요청을 함께 보내지 않았다
- [ ] 시작 그림 속 인물이 대본의 말하는 사람·듣는 사람 관계와 맞다
- [ ] 말하는 사람마다 얼굴이 보이는 시작 그림이 따로 있다
- [ ] 듣는 사람 반응 영상을 같은 묶음에 넣었다(긴 대사는 2개 이상)
- [ ] 정지 유발어를 쓰지 않았다. 컷당 행동은 2개까지다
- [ ] 생성 뒤 0.25초 펼치기로 얼굴·손·옷을 시트와 대조했다

### 편집
- [ ] 말하는 얼굴은 목소리 끝 +0.12초에서 잘랐다
- [ ] 다시 쓴 화면(인서트·반응)마다 시간대·빛·입 다묾·동작을 새 자리와 대조했다
- [ ] 같은 화면 3초 넘김이 없다. 같은 반응 화면을 한 장면에 두 번 쓰지 않았다
- [ ] 글자는 실제 크기 프레임으로 확인했다(원근·겹침·크기)
- [ ] 꼭 들려야 할 효과음은 자동 줄임(덕킹)에서 뺐다
- [ ] 최종 음량을 측정했다(−14 LUFS, 트루피크)
- [ ] 고친 뒤 **처음부터 끝까지** 다시 시트를 봤다(고친 곳만 보지 않음)

### 업로드 묶음
- [ ] 제목 형식(`[시리즈 N화] 훅`), 결말을 드러내지 않음
- [ ] 설명란: 첫 줄 훅, 이전 화 링크, 다음 화 날짜, AI 안내, 해시태그
- [ ] 고정 댓글이 질문으로 끝남
- [ ] 커버 3종, 폰 크기에서 글자가 화면 안에 들어감
- [ ] AI 사용 = 예, 아동용 아님, 유료 프로모션 없음
