# 영상 공모전 제작 에이전트

3팀(서브에이전트)이 순서대로 협업해 공모전 영상을 기획→생성→검수한다.

> **제작 워크플로우는 [AGENTS.md](./AGENTS.md)를 따른다.** (스토리→이미지→영상 순서, 단계별 사용자 확인 게이트)
@AGENTS.md

## 파이프라인

```
01_요강/  ──▶  [기획팀]  ──▶  02_기획/기획안.md
                              │
                              ▼
                          [생성팀]  ──▶  03_스토리보드/  +  04_생성물/(images, videos)
                              │
                              ▼
                          [검수팀]  ──▶  05_검수/검수리포트.md  ──▶ (수정 필요 시 해당 팀으로 반려)
```

## 팀 (.claude/agents/)
| 팀 | 에이전트 | 역할 | 입력 → 출력 |
|---|---|---|---|
| 기획팀 | `planning-team` | 분석 + 기획 | `01_요강/` → `02_기획/기획안.md` |
| 생성팀 | `generation-team` | 보드 + 이미지 + 영상 | `02_기획/` → `03_스토리보드/`, `04_생성물/` |
| 검수팀 | `review-team` | 최종 점검 | 전체 → `05_검수/검수리포트.md` |

## 사용법
1. 공모전 요강 파일을 `01_요강/`에 넣는다.
2. 메인에서 순서대로 호출: 기획팀 → 생성팀 → 검수팀. 검수팀이 반려하면 지정된 팀으로 되돌려 재실행.

## 의존성
- **이미지 프롬프트**: 전역 `$image-prompt-formatter` 스킬의 5단 구조(주제-행동-조명-분위기-카메라 구도)를 따른다.
- **Higgsfield MCP**: 영상 생성에 필요. **현재 미연결** — 연결 전까지 생성팀은 프롬프트·생성순서까지만 완성한다.
