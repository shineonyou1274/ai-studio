## GATE S31 — 최종 컷 셀렉 · 프리미어 임포트

**왜:** 버전 스택 중 '이거다' 하는 최종본만 편집으로 넘긴다. 어중간한 버전이 섞이면 타임라인이 오염된다.

### 31-1. 최종 컷 셀렉 (S29 콘솔의 채택 결과 확정)
- 영상 버전 콘솔(`results.json`)에서 **씬별 채택 버전 1개씩**을 최종 확정. 콘솔 상단 **[최종 컷 셀렉으로 진행]**을 누르면 채택본 목록이 잠긴다.
- 산출: `final_selects.json` — 씬번호 → 최종 클립 경로(오디오 포함본 + 분리 스템 경로) 매핑.
- **누락·미채택 씬 점검**: 모든 씬에 채택본이 있는지 확인. 빠진 씬은 STAGE 4로 되돌려 채운다.

### 31-2. 프리미어 브리지 준비 (CEP 파일드롭 방식)
> MCP 서버 없이 **CEP 브리지를 temp command/response 파일로 직접 제어**한다(메모리: reference-premiere-bridge-filedrop). Premiere 데스크톱 + 브리지 확장(CEP 패널)이 떠 있어야 한다.
1. Premiere가 실행 중이고 대상 프로젝트가 열려 있는지 확인(없으면 사용자에게 실행 요청 — 편집은 생성 엔진과 무관, 이 단계 직전 확인).
2. 브리지의 command 파일 규약 확인(예: `bridge/command.json` 쓰기 → 패널이 실행 → `bridge/response.json` 회신).
3. `final_selects.json`의 클립들을 프로젝트 **빈(bin)으로 import** (command: import, paths[]).

### 31-3. 임포트 확인
- response로 임포트된 클립 수·경로를 확인. 실패분은 경로/코덱 점검 후 재시도(mp4 H.264 권장, 문제 시 트랜스코드).

**산출물:** `final_selects.json` + 프리미어 빈에 임포트된 최종 클립.

## GATE S32 — 시나리오 시간순 배열 · Export

**왜:** 편집의 뼈대 = 스토리 시간순. 씬 리스트 순서 그대로 타임라인에 깔면 러프컷이 선다.

### 32-1. 시간순 시퀀스 조립 (브리지 command)
1. **시퀀스 생성**: 프레임 비율(STAGE 2)·해상도(720/1080)·fps에 맞춰 새 시퀀스.
2. **순서 = SCENARIO_BIBLE 씬 리스트(시간순).** `final_selects.json`을 씬번호 오름차순으로 정렬해, V1 트랙에 **머리를 맞대어(end-to-end) 순차 배치**.
   - command 예: `{op:"place", track:"V1", clips:[{path, start}]}` — start를 이전 클립 끝에 이어 누적. 오디오는 A1(대사)·A2(SFX)로 분리 스템을 동반 배치(BGM 트랙 없음 — 규칙 0-[B]).
3. **컷 경계 = 씬 경계.** 기본은 하드컷 순차. **타이트 컷은 생성 duration이 목표보다 길므로(엔진 최소값, Q25-3 변환 규칙) VIDEO_PLAN의 목표 컷 길이(1.5~2.5s)로 트림**해서 배치한다 — 슬로우 컷은 생성 길이 그대로. (디졸브·트랜지션은 사용자 요청 시만.)

### 32-2. 러프컷 점검 (사용자)
- 프리미어에서 재생하며 순서·길이·오디오(대사 음성 일관성·SFX) 확인. 순서 오류는 씬번호 재매핑으로 교정.
- **음성 일관성 최종 육안·청취 확인**: 인물별 목소리가 전 씬 동일한지(규칙 7). 어긋나면 STAGE 4 S26 락으로 그 씬 재생성 후 교체.

### 32-3. 미세 편집(선택) · Export
- 사용자가 원하면: 컷 트림, 씬 순서 미세조정(스토리 시간순 유지), 대사 타이밍, SFX 레벨.
- **BGM은 이 파이프라인에서 넣지 않는다.** 음악이 필요하면 사용자가 별도로 결정·삽입(편집 단계에서 사용자 몫).
- Export: 프레임 비율·해상도에 맞춰 마스터 출력(H.264/H.265). 4K 지향이면 Magnific `video_upscale` 후처리.

### 32-4. 산출물 기록 (덮어쓰기 금지)
```
projects/narrative/{name}/v{날짜}/
  final_selects.json
  premiere/{name}.prproj  (또는 브리지 로그)
  exports/{name}_master_{프레임}_{해상도}_v{날짜}.mp4
  pipeline.jsonl  (STAGE 1~5 기록)
```

**산출물:** 시나리오 시간순으로 배열된 프리미어 시퀀스 + 마스터 export.

### 32-5. (숏폼 트랙, 선택) 1분 훅 파생 — 이중 자산 📚 강의: 슬라이드54·68·「하나를 만들고 두 벌로 쓴다」
> 본편이 완성되면 **같은 소스에서 1분 훅 3종**을 재편집으로 뽑는다(추가 생성 크레딧 0 — 편집만). 본편은 붙잡는 자산, 훅은 끌어오는 자산.
- **훅 A(표준형)**: ①굴욕 → ③떡밥 → ⑤반전 직전에서 끊기.
- **훅 B(압박형)**: ④의 최악 장면을 맨 앞에 → ①로 점프 → ③.
- **훅 C(리액션형)**: ⑤의 경악 리액션을 먼저 → "10초 전" 자막 → ①로 되감기.
- 각 훅 끝에 1초 "본편에서 계속" 카드. 제목 3안(스포일러 훅 문법 — S2) + 썸네일 프레임 지정(S24-5). **한꺼번에 올리지 말고 3일 간격 멀티포스팅** — 본편 하나로 유입 기회 3번.
