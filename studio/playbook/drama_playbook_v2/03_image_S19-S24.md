## GATE S19 — 캐릭터 시트 (gpt-image-2, 1장에 특징 총집합) ★

**왜:** 컷마다 얼굴·의상이 바뀌면 드라마가 아니다. **인물마다 1장의 캐릭터 시트**에 특징을 모두 담아, 이후 전 씬의 정체성 ref로 잠근다. (사용자 요구: "각각의 캐릭터 시트를 1장에 모두 특징이 담기게끔 gpt2로 생성.")

### 19-1. 캐릭터 시트 = 1장 멀티뷰 컴포지트 (gpt-image-2) 📚 강의: 슬라이드27·「빙산의 생리층」
> **캐릭터 시트는 빙산의 '생리층'(눈에 보이는 것)을 박제하는 장치**다. S3에서 설계한 생리층(나이·외모·습관)이 그대로 시각 특징이 되고, 사회층(계급·직업)은 의상·소품으로, 심리층은 시그니처 표정으로 번역된다.

**gpt-image-2**를 쓴다(정확한 라벨·정렬·다뷰 렌더에 강함). 한 장 안에 인물의 특징을 **모두** 배치:
- **정면 · 3/4 · 측면 · 뒷모습** 얼굴/상반신 (표정 중립 1 + 시그니처 표정 1)
- **전신 T-포즈/자연 포즈** (체형·키·자세)
- **시그니처 의상 클로즈업**(원단·질감·색) + **소품**(SCENARIO_BIBLE의 캐릭터 디테일 취향 = 버릇 소지품)
- **헤어·핸즈 디테일** 인서트
- **컬러 팔레트 스와치**(그 인물의 지정색 — 색코드 설계와 연동)
- **★ 의상 색 아크 3단계** 📚 강의: 슬라이드38·「의상 색 코딩」 — 인물의 아크가 의상 색으로 이동하게 시트에 미리 박는다(예: 무력=탁한 중간색 → 각성=진한 원색 → 완성=검정/흰 — 구체 색은 취향 프로파일로). **대사 없이 도덕·감정 상태를 읽히는 무의식 채널**이며, 세로 화면에선 의상이 배경보다 점유율이 높아 색 변화만으로 아크가 즉시 읽힌다. 아크가 있는 인물(주인공·악역)은 시트에 단계별 의상 3벌을 나란히 배치하고, 씬 생성 시 그 비트의 단계 의상을 지정한다.
- 라벨(한/영): 이름·나이·핵심 특징 키워드
- **MODE 훅:** QUALITY = 인물별 3안 생성 → 선택. ECO = 1안 + 수정 루프.

### 19-2. 프롬프트 원칙
- SCENARIO_BIBLE의 주인공 3차원 시트(생리·사회·심리) + 캐릭터 디테일 취향을 **시각 특징으로 번역**.
- **배경은 뉴트럴(무지·회색)** — 시트는 정체성 ref용이라 배경 미술을 넣지 않는다(씬에서 입힌다).
- **실존 인물·배우 얼굴 금지**(규칙 4). "잘생긴 아이돌 평균 얼굴"로 뭉개지지 않게, 개성 있는 특징(비대칭·점·흉터·눈매)을 명시해 **식별 가능한 고유 얼굴**을 만든다.
- 규칙 0-[A]의 IDENTITY LOCK 문법 + `06`의 룩 상수 주입. 단 시트는 **정면 포함 멀티뷰가 목적**이라 규칙0의 '정면 배제'는 시트에 한해 예외(씬에는 적용).

### 19-3. 생성 · 확정
- 4종 프리뷰 승인(MODEL=gpt_image_2 / 해상도·안 수는 MODE / 오디오 N/A / 비율=시트는 가로 넓게 권장). **안 수는 19-1 MODE 훅을 따른다 — QUALITY=인물별 3안 → 사용자 선택 / ECO=인물별 1안 → 수정 루프.**
- 확정 시트를 **얼굴 크롭 + 히어로 의상 크롭**으로 잘라 **ref 세트**로 저장(다운스케일: 얼굴 ~1280px, <300KB — 대용량 ref는 실패·지연 주범).
- 인물이 여럿이면 각자 시트. **조연·군중은 얼굴 뭉갠 아웃포커스**로 처리(시트 불필요).

> **엔진 노트:** gpt-image-2 경로 = Higgsfield `generate_image(gpt_image_2)` / Magnific `images_generate(gpt-2)` / 메인 repo `system/generate_gpt_image.mjs`(CometAPI). 셋 중 연결된 것. 결과는 `projects/narrative/{name}/v{날짜}/character_sheets/{인물}.png`.

**산출물:** 인물별 캐릭터 시트 1장 + ref 세트(얼굴·의상 크롭, 다운스케일).

## GATE S20 — Voice Sheet 준비 (연결고리)

**왜:** 사용자 요구 — 캐릭터 시트에는 외관뿐 아니라 **음성 특성**도 박제되어야 하고, 전 씬에서 동일해야 한다. 여기서는 **음성 슬롯을 예약**하고, 실제 락 워크플로우는 STAGE 4의 S26에서 완성한다.

### 20-1. 각 캐릭터 시트에 Voice 슬롯 추가
| 필드 | 내용 |
|---|---|
| 목표 음색(자유서술) | "낮고 건조한, 감정 억제된 40대 남성" 등 |
| 소스 방식(예약) | ⓐ 샘플 영상 몇 개로 정할지 / ⓑ 기존 보유 음성 첨부인지 (S26에서 확정) |

> **작법 연결:** 음색은 캐릭터의 진짜 성격(true character)과 일치해야 한다(예: 억제형 주인공 = 낮고 절제된 톤). SCENARIO_BIBLE의 아크에 맞춰 초안 음색을 제안한다.

**산출물:** 인물별 Voice 슬롯(목표 음색 + 소스 방식 예약).

## GATE S21 — 화각 밸런스 배정

**왜:** 드라마는 화각의 리듬이다. **하이·로우·사이드·더치·오버더숄더·데마이·인서트**를 밸런스 있게 써야 눈이 지루하지 않다. (사용자 요구 그대로.) 정면 아이레벨 풀샷은 광고/드라마 모두 값싸 보인다.

### 21-1. 화각 밸런스 카드 (`06` 참조 — 씬별 1개 배정)
| 화각 | 언제 | 심도 |
|---|---|---|
| **하이앵글** | 인물을 약하게·내려다봄, 상황 조망 | 얕게 |
| **로우앵글** | 인물을 강하게·위압, 권력 | 얕게 |
| **사이드(프로파일)** | 대치·거리감·관찰 | 얕게 |
| **더치(기울임)** | 불안·긴장·붕괴 | 얕게 |
| **오버더숄더(OTS)** | 대화·시선의 주고받음(대사 씬 주력) | 앞흐림 뒤선명 |
| **데마이 CU(망원 얕은 심도)** | 감정·표정 정보, 보케 | 극얕게 |
| **인서트/매크로** | 소품·손·시선·상징(대사 없음) | 극얕게 |
| **★ 오브젝트 POV** 📚 강의: 슬라이드38 | 사물 안/밑에서 인물을 올려다보는 광각 로우앵글(가방 안·트렁크 안·기계 안) — **"이 사물이 곧 중요해진다"는 시각 신호** + 얼굴 일관성 부담 없이 '연출됐다'는 인상. 셋업 소품과 겸용하면 효율 2배 | 광각 |

### 21-2. 배정 규칙 (에이전트가 씬 리스트에 매핑 → 사용자 확인)
- **프레임별 화각 예산** 📚 강의: 슬라이드7·「스크린이 줄수록 얼굴이 커진다」 — **취향이 아니라 물리 법칙**:
  | 프레임 | 예산 |
  |---|---|
  | 세로 9:16 (모바일) | **반신~CU 위주. 와이드 설정샷은 막당 1컷 이하.** 표정이 정보의 전부 — 정보를 얼굴에 실어라. 와이드를 쓰면 정보가 사라진다 |
  | 가로 16:9 (큰 화면) | 와이드·풍경·군중·긴 침묵 허용. 단 대사·감정 정보는 여전히 미디엄~CU로 |
- **인접 씬 동일 화각 금지**(로테이션). 정면 온-액시스 CU는 **감정 피크 리액션에만**(작품당 소수).
- **대사 씬 = OTS·3/4·리액션 CU** 위주(정면 립싱크 최소화 → STAGE 4 립싱크 부담·음성 드리프트 리스크 감소).
- **인서트 씬 = 매크로·오브젝트 POV**(셋업/페이오프 소품은 심을 때와 회수할 때 **동일 앵글**로 — 명작 원리).
- **★ 가짜 리버스샷 (투샷 회피 — AI 실전)** 📚 강의: 슬라이드46: 두 인물의 대치·교감은 **각자 단독 정면/3.4 CU를 맞교차**로 편집하면 마주보는 것처럼 읽힌다. **두 사람을 한 프레임에 넣지 않으므로 투샷에서 생기는 캐릭터 일관성 붕괴를 원천 회피.** 꼭 필요한 투샷만 남기고 대치 씬은 기본 이걸로.
- **★ 무표정 홀드 컷 (결말 정보 선지급과 세트):** S7에서 결말 정보를 선지급했다면, 그 뒤의 **무표정 CU 홀드**가 저절로 아파진다 — AI 배우의 미세 표정 연기 불안정을 **정보 설계 + 홀드**로 대체. 감정 피크에 과장 표정을 시키지 말고 무표정 홀드를 쓴다.
- **얕은 심도 기본**(사용자 요구: "심도가 얕은 이미지를 활용"). 3레이어 FG/MG/BG 분리 강제.
- S17에서 사용자가 씬별로 고른 화각이 있으면 그것을 우선.

### 21-3. 렌즈·구도 문법 — 시선의 권력 (🎬 비전: Part 2·4)
> 화각(앵글)에 **렌즈(mm)와 구도 장치**를 더해 씬의 심리를 정밀 지정한다. "Cinematic shot"이라고만 적는 건 감독의 태도가 아니다 — **의도에 맞춰 mm 수와 카메라 높이를 지시하라.** (프롬프트 조각 = `06` [렌즈 문법])

**렌즈 심리학 (씬 감정 → mm 선택):**
| 렌즈 | 심리 | 언제 |
|---|---|---|
| **광각 16~24mm** | 왜곡·소외·공간의 압도 — 인물보다 '세계'를 보여줌. 가장자리 왜곡 = 불안 | 고독·기괴함·세상에 짓눌린 개인(하이앵글 광각) / 영웅화(로우앵글 광각) |
| **표준 50mm** | 인간의 눈 — 왜곡도 과장도 없는 '정직한 목격' | 담백한 일상·가족·다큐 톤(다다미 샷과 세트) |
| **망원 85~200mm** | 압축·관음·침투 — 배경을 붙여버리고 공기를 제거 | 감시당하는 느낌·군중 속 고독·인물 영웅화·심리적 침투(호흡이 들리는 CU) |

**구도 장치 (미장센 — 선택 적용):**
- **Z축 레이어링**: 전경(흐릿한 사물)–중경(인물)–후경. **전경에 흐린 물체를 걸면 관객은 '훔쳐보고 있다'는 무의식적 몰입**을 얻는다(`blurred foreground object`, `view through something`).
- **프레임 속 프레임**: 문틈·창·거울 안에 인물을 가둔다 — 고립·관음·용인되지 않는 관계의 시각화.
- **1점 투시**: 모든 선이 소실점 하나로 — 강제 집중·운명적 공포·시스템의 차가움. (플랫 파스텔 대칭이면 반대로 동화적 아이러니.)
- **다다미 샷**: 앉은 눈높이(60~90cm)·고정 — 권력도 공포도 아닌 **동등하게 관조하는 시선**. 가정·일상 드라마.
- **버즈아이(수직 부감)**: 인물을 바닥에 납작하게 — 운명의 미로에 갇힌 인간, 신의 시선. `true top-down, camera perpendicular to the ground`.
- **심도 선택 기준**: 감정·단절 = 얕게(세상을 지운다) / **맥락·인과가 중요하면 깊게**(딥 포커스 — 지친 소방관과 불탄 건물을 한 화면에: 인물과 원인을 연결). 얕은 심도 기본값의 **의도적 예외**로 딥 포커스 씬을 1~2개 배치하면 리듬이 생긴다.
- **랙 포커스(영상 전용 예고)**: 초점이 A→B로 이동 = '주도권·생각의 이동'을 대사 없이. S27 카메라 무브에서 지정.

**산출물:** 씬별 화각 + 렌즈(mm) + 심도 + 구도 장치 지정(STORYBOARD_PLAN에 병합).

## GATE S22 — 조명 룩 (작품 지정으로 룩 입히기)

**왜:** 조명이 드라마의 격을 만든다. 사용자 요구: **"원하는 조명 스타일을 원하는 작품명을 선택하게 해서 하이키, 로우키, 네거티브필 등 룩을 입힐수 있게."** — 작품명을 조명 '레퍼런스'로 쓰되, **그 작품의 장면을 복제하는 게 아니라 조명 원리만 추출**한다(표절 경계).

### 22-1. 조명 룩 지정 (작품 앵커 + 씬 오버라이드 확정)
> **재질문 금지:** 전역 조명 룩은 이미 **S18-1에서 `global_look.json`에 확정**되어 있다 — 그 값을 기본값으로 **제시만** 하고 다시 묻지 않는다(사용자가 변경을 요청할 때만 갱신). 이 GATE의 일은 ①작품 앵커 처리(22-2) ②비트별 씬 오버라이드(22-3) 확정이다. 아래 표는 S18-1과 같은 레시피 사전(참조용).
> **🎬 조명의 제1원칙 (비전: Part 3 — 괴테):** AI 이미지가 밋밋한 이유는 그림자가 없어서다. AI는 본능적으로 밝고 예쁘게 만들려 한다. **"빛을 추가하지 말고 어둠을 추가하라"** — deep shadows·negative fill·silhouette로 빛을 '귀한 것'으로 만들어라. 그리고 "이 빛은 어디서 와서, 인물의 어디를 때리고, 어떤 그림자를 남기는가?"에 답할 수 있어야 조명 지정이 끝난 것이다. 단순 `Cinematic Lighting`은 게으른 기획이다.

### 22-3. 색코드 조명 (비트 연동) 📚 강의: 슬라이드38·46·「색이 대사보다 먼저 말한다」
- 가치 변화 비트마다 조명·색을 바꾼다(예: 억압 = 콜드 블루 로우키 / 반전·해방 = 웜 앰버 역광). STORYBOARD_PLAN의 씬 오버라이드에 씬별 조명을 기록.
- **색 = 권력·도덕의 언어:** 억압자 쪽을 차게/밝게(하이키), 주인공 쪽을 어둡게 깔았다가 반전에서 반전시키는 식으로, **색의 소유권이 이동하는 설계**가 가능하다. 인물 의상 색 아크(S19)와 조명 색코드가 **같은 방향으로 이동**해야 한다(의상은 검정으로 가는데 조명은 계속 파스텔이면 어긋난다).
- **★ 이중 타임라인 색코드 (시그널 원리):** 과거·현재(또는 회상·꿈)가 오가는 이야기면 **타임라인마다 색·질감을 고정**한다 — 예: 과거 = 웜톤·황갈·필름 그레인 강하게 / 현재 = 콜드톤·시안·클린. **자막 없이 0.5초 만에 시대가 판별**되게. `06`의 타임라인 색코드 조각 사용.

## GATE S23 — 미술 (컬러 콘트라스트 · 컬러 밸런스 · 특색 배경)

**왜:** 사용자 요구 — "미술효과가 이미지에서 아주 중요… 디테일하게 질문해서 컬러콘트라스트와 컬러밸런스 등 평범하지 않은 특색있는 배경." **평범한 배경을 막는 것이 이 GATE의 임무.**

### 23-1. 미술 정밀 확정 (S18-2 질문 결과 + 추가 심화) 🎬 비전: Part 1·3
`06`의 [미술·조명 정밀 질문 카드]로 씬(또는 공간) 단위로 확정:
- **지배색 + 액센트색(보색)** — 컬러 밸런스의 축. 예: "청록 벽 + 주황 조명" "회녹색 공간 + 핏빛 소품 하나".
- **컬러 콘트라스트 전략 (알버스의 상호작용):** 색은 상대적이다 — **주인공을 튀게 하려면 주인공의 색을 바꾸지 말고 배경색을 바꿔라.** 배경을 인물의 보색으로 두면 조명 없이도 인물이 튀어나온다(Pop-out). 피부톤은 오렌지 스펙트럼 → 배경 청록(틸앤오렌지)이 물리적으로 가장 강한 인물 분리다. 같은 배색을 심리로 비틀 수도 있다(따뜻한 인물 vs 냉혹한 세상 = 단절된 고독).
- **이텐의 색채 대비 3종 (씬 감정 → 대비 선택):** 보색 대비(강렬·갈등·액션 — Blue vs Orange) / 한난 대비(감성적 거리감 — 차가운 바깥 vs 따뜻한 실내) / 명도 대비(느와르·실루엣 — 색보다 밝고 어둠으로 형태를).
- **시네마틱 그레이딩(필름 스톡)** — 룩을 한 단어로 잠그는 지름길(조각 = `06`): 웜 스킨·파스텔(인물 감성) / 텅스텐 야경·할레이션(도시 야경·네온) / 저채도 고대비(전쟁·재난·거침) / 고채도 원색(뮤지컬적 비현실) — S18의 전역 그레이드와 충돌하지 않게 하나로.
- **전경-중경-후경 레이어** — 데드스페이스 금지, 각 레이어에 의도적 소품(단, 자막/여백 자리는 비움). 전경 흐림 = 훔쳐보기 몰입(21-3).
- **질감·환경 디테일** — 빛샘·먼지·습기·반사·낡음. 평범을 깨는 요소.
- **상징 소품** — SCENARIO_BIBLE의 셋업/페이오프 오브제를 배경 미술에 심는다.
- **★ 푼크툼 디테일 (완벽 금지 원칙):** AI는 평균을 학습해 매끈하고 영혼 없는 화면을 만든다(스투디움). **씬마다 '찌르는 디테일' 1개를 의도적으로 심어라** — 금 간 안경알, 한 짝만 남은 아이 장화, 사진 모서리의 지문. 설명하지 않는 사소한 이물감이 관객을 찌른다. S8에서 받은 인물 푼크툼 + 씬 취향 태그를 여기서 소품으로 번역.
- **★ Atmosphere 원칙 (What이 아니라 How):** 객체 나열은 묘사일 뿐이다. **"비 오는 거리"(What)가 아니라 "비에 젖은 아스팔트의 차가운 질감과 고독한 공기"(How)**를 지시하라 — 공간의 온도·습도·밀도가 프롬프트에 있어야 한다.

### 23-2. 공간 일관성(같은 장소 반복 씬) + 공간 색온도 고정 📚 강의: 슬라이드42·「공간별 색온도 고정」
- 동일 장소가 여러 씬에 나오면 **공간 plate(배경 키 이미지)를 먼저 1장 확정**하고, 그 장소의 다른 씬은 그 plate를 ref로 잠가 공간이 튀지 않게 한다(배경 일관성). — 인물 시트와 같은 락 원리.
- **★ 공간별 색온도 고정 코드 (나의 아저씨 원리):** 등장 공간마다 색온도를 고정해 **컷만 바뀌어도 감정 좌표가 전달**되게 한다. 예(원리 — 실제 색은 취향으로): 일터=창백한 형광(외력의 공간) / 주인공의 방=저조도 냉색(생존의 공간) / 안식처=따뜻한 텅스텐(유일하게 따뜻한 공간). 회복 서사면 후반부로 갈수록 낮·햇빛 비중을 늘려 **회복을 색으로 말한다.** 공간 plate 생성 시 이 색온도를 박제한다.
- **셋업/페이오프 소품 락:** ③에서 심고 ⑤에서 회수하는 오브제는 **같은 소품 이미지를 ref로 잠가 두 컷을 같은 세션에서 생성** — 동일 앵글 + 동일 ref = 일치 보장. (심을 땐 하찮게, 회수할 땐 같은 구도로.)

**산출물:** 씬/공간별 미술 지정(지배색·액센트·레이어·질감·상징) + (반복 장소) 공간 plate + **공간 색온도 표**.

**왜:** 이제 480p 방향 + 캐릭터 시트 + 화각 + 조명 + 미술이 다 섰다. **고화질 본 이미지**를 뽑는다. (사용자 요구: "알렉사 아리 카메라의 질감과 색감을 활용.")

```
COMMON = 규칙0[A](캐릭터 락·화각 밸런스·ARRI 룩) + DRAMA_IMG_ENHANCE + global_look(전역 미술·조명)

  + 프레임 비율(S13)
  + 씬 카드(장소·인물·행동·값 변화)

medias(ref) = 등장 인물의 캐릭터 시트 얼굴·의상 크롭 (+ 반복 장소면 공간 plate)
```

### 24-2. 생성 플로우 (엔진 무관 공통 + MODE 훅)

   - **MODE 훅:** QUALITY = 씬당 **2안**(가능하면 서로 다른 엔진 병렬) → 베스트 채택, 2k. ECO = 씬당 **1안**, 1k~2k, 수정 요청된 씬만 재생성.
3. **폴링·다운로드는 백그라운드 에이전트에 위임**(동시 한도 준수, 폴백: 순차+체크포인트). 완료분을 `images/{scene}.png`로.

> **4종 프리뷰(승인 필수):** MODEL(nano_banana_2/gpt_image_2/seedream-4 중, 씬 성격에 맞게) / 해상도 2k / 오디오 N/A / 비율=S13 + 씬별 요약 테이블 + ref 파일명·용도 + "규칙0[A]+DRAMA_IMG_ENHANCE+global_look 주입됨" 표기.
