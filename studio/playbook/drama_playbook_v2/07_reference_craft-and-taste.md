# 1부 · 작법 카드 (STAGE 1 검증 도구)

## 카드 A — 시학 6요소 (아리스토텔레스) · 플롯 우선
플롯 > 성격 > 사상 > 언어 > 노래 > 볼거리. **플롯이 영혼**이다. 좋은 플롯 = **급전(peripeteia, 상황의 급반전)** + **인식(anagnorisis, 진실의 깨달음)**이 동시에 터져 **카타르시스**를 만든다. → *STAGE 1 점검:* "우리 이야기에 급전과 인식이 있는가? 절정에서 둘이 겹치는가?"

## 카드 B — 시드필드 3막 · 구성점 (Paradigm)
```
1막 설정(25%) ─[구성점1]─ 2막 대립(50%) ─[미드포인트]─ ─[구성점2]─ 3막 해결(25%)
```
- **구성점(Plot Point)** = 이야기를 다른 방향으로 홱 트는 사건. 구성점1 = 주인공이 되돌릴 수 없는 문으로 진입. 구성점2 = 최악의 순간, 3막 진입 동력.
- **미드포인트** = 2막의 척추. 판을 뒤집는 거짓 승리/거짓 패배. 없으면 2막이 늘어진다.
→ *점검:* 구성점1·2·미드포인트가 명확한 '사건'인가(감정 아니라 행동)?

## 카드 C — 맥키 5단계 · 가치 변화 · 지배 아이디어
- **5단계**: 도발적 사건 → 상승 갈등 → 위기(선택) → 절정 → 해소.
- **가치 변화**: 씬·막의 시작과 끝에서 핵심 가치의 **부호가 뒤집혀야** 한다(+신뢰→−배신). 안 뒤집히면 그건 씬이 아니라 사건 나열.
- **Gap(간극)**: 인물의 기대와 실제 결과의 간극이 이야기의 에너지. 간극이 클수록 극적.
- **지배 아이디어**: "가치 + 원인" 한 문장. 절정에서 이게 증명된다. = 전제의 작동 버전.
→ *점검:* 매 씬이 값을 바꾸는가? 지배 아이디어가 절정에서 증명되는가?

## 카드 D — 에그리 전제(Premise) · 3차원 캐릭터 📚 강의: 슬라이드26~27
- **전제**: 이야기가 증명하려는 한 문장(원인→결과). 예: "탐욕은 파멸을 부른다." 전제 없는 이야기는 "목적지 없는 항해"다. 모든 씬은 전제를 증명하는 증거 — 증명 안 하면 잘라낸다.
- **부정 테스트**: 전제를 뒤집어 본다. 뒤집어도 이야기가 성립하면 그 전제는 약하다. 하나로 못 박힐 때까지.
- **3차원 캐릭터(빙산)**: 생리(몸 — 캐릭터 시트(S19)가 잡는 층)·사회(관계/계급 — 정체 격차가 생기는 층)·심리(가치/두려움 — 진짜 엔진). 셋이 다 있어야 입체. "청소부인데 회장"은 사회층 반전 = 설정일 뿐, **"왜 숨겼는데?"(심리층)가 있어야 캐릭터**다.
- **안타고니스트도 전제를 가진다**: 악을 위한 악 금지. 적에게도 자기 논리를 준다. **"적은 주인공 의지력의 총합"(맥키)** — 적이 강할수록 승리가 커진다.
→ *점검:* 전제가 한 문장인가(부정 테스트 통과)? 주인공·적 둘 다 3차원인가?

## 카드 E — Want / Need / Lie / Wound · 아크 4유형 (호튼/Weiland)
- **Want**(외적 목표, 플롯) ↔ **Need**(내적 진실, 주제)의 충돌이 아크. **Lie**(잘못된 신념)는 **Wound**(과거 상처)에서 나온다.
- **아크 4유형**: ①긍정(거짓→진실, 성장) ②부정-타락(진실→거짓) ③평면(주인공 불변, 세계를 바꿈) ④비극-환멸.
- **미드포인트에서 Want↔Need 우세가 뒤집힌다**(진실을 향해).
→ *점검:* Lie가 Wound에 뿌리내렸는가? 결말에서 Need가 해소/거부되며 아크가 닫히는가?

## 카드 F — 성격묘사 vs 진짜 성격 (Characterization vs True Character)
- **성격묘사** = 겉으로 관찰되는 것(직업·말투·외형). **진짜 성격** = 압박의 정점에서 하는 **선택**으로만 드러난다.
- 둘의 **간극**이 캐릭터의 깊이. 겉과 속이 같으면 평면적.
→ *점검:* 주인공이 극한에서 '겉모습과 다른 선택'을 하는 순간이 있는가?

## 카드 G — 비트 프레임: Save the Cat 15비트 / 8시퀀스
- **Save the Cat 15비트**: 오프닝이미지 · 주제명시 · 설정 · 기폭제 · 토론 · 2막진입 · B스토리 · 재미와놀이 · 미드포인트 · 악당접근 · 절망(모든게무너짐) · 영혼의어둠밤 · 3막진입 · 피날레 · 마지막이미지. + **'고양이를 구하라'**(초반 공감 장치) 필수.
- **8시퀀스**: 3막을 8개 미니무비로. 각 시퀀스 = 미니 목표·미니 위기·핀치. 긴 호흡/에피소드에 강함.
→ *선택:* 감정선 촘촘·상업 = 15비트 / 플롯 복잡·장편 = 8시퀀스.

## 카드 H — 영웅의 여정 12단계 (원형) · 로그라인 · 스노우플레이크
- **영웅의 여정**: 일상 → 소명 → 거부 → 멘토 → 관문 → 시련/동료/적 → 접근 → 시련(죽음) → 보상 → 귀환길 → 부활 → 귀환(영약). 신화·성장·모험에 강한 뼈대(강제 아님, 참고).
- **로그라인 공식**: `[상태의 주인공]이 [사건]으로 [목표]를 좇지만 [적대/대가]가 막는다` + 아이러니. 4요소(공감 주인공·명확 목표·강한 반대·역설) 필수.
- **스노우플레이크 7단계(김사라식 창작 절차)**: ①한 문장(로그라인) → ②한 문단(3재난+결말) → ③인물별 요약 → ④한 페이지 → ⑤인물 시놉시스 → ⑥4페이지 → ⑦씬 리스트. **작게 시작해 눈덩이처럼 키운다** — STAGE 1의 진행 자체가 이 절차다.

## 카드 I — 명작에서 추출한 '원리' (표면 복제 금지, 원리만)
> 아래는 특정 작품을 베끼라는 게 아니라, **검증된 서사 장치의 원리**다. 100% 오리지널 소재에 적용한다.
- **하강을 계단으로**(브레이킹 배드): 변화를 '경사로'가 아니라 눈금 매긴 '계단'으로. 시즌/막마다 정확히 1개의 '돌아올 수 없는 결정'.
- **셋업/페이오프 사거리 등급제**: 반전 소품을 하찮은 인서트로 미리 심고, 심을 때·회수할 때 **동일 앵글**. (AI: 동일 소품 ref를 잠가 두 컷을 같은 세션에서 생성.)
- **감시를 친밀로 뒤집기**(나의 아저씨): 새 정보 없이 '소리의 방향'만으로 감정 정점. 관객을 관찰자가 아닌 공모자로.
- **3회 절제 → 1회 폭발, 운동에너지 치환**: 울어도 되는 순간을 반복해 참게 하고, 폭발은 1회 + 눈물이 아니라 행동(달리기)으로. 음악은 감정을 만드는 게 아니라 끝난 뒤 정산.
- **선언 대사 절약**: 주제를 직접 말하는 명대사는 작품당 1~2회. 시그니처 라인의 3단 배치(뜻이 뒤집히게).
- **극적 아이러니 > 미스터리**: 관객은 알고 인물은 모르는 정보 격차 = 공짜 서스펜스.
- **색코드**(의상·공간): 인물·공간마다 고정 색으로 도덕 상태·감정 좌표를 대사 없이 전달. (→ STAGE 2·3 미술·조명에 직결.)
- **이중 타임라인/오브제 하나에 비밀**(시그널식): 단일 오브제가 서사 전체를 나른다 — 짧은 분량에 최적.

## 카드 J — 시청 계약 (기초이론) 📚 강의: 슬라이드4~9
- **영화 = 선불 계약**(티켓·2시간 선지불 → 인내 자본, "어떻게 끝낼까"를 설계). **드라마 = 매 순간 재계약**(공짜·스와이프, "어떻게 떠나지 못하게 할까"를 설계). 숏폼은 재계약 주기가 **3초**.
- 영화는 한 번 터뜨리고(단일 아치), 드라마는 매회 끊는다(회차 아치 + 시즌 아치, 떡밥 분할 상환). 숏폼은 90~150초 마이크로 3막 사이클.
- **화면 크기 문법**: 극장=와이드·군중·긴 침묵 허용 / TV=CU·대사 중심 / 폰 세로=**표정이 정보의 전부, 자막 상시, 절반은 무음 시청, 와이드 금물**. 취향이 아니라 물리 법칙.
- **결론: "영화처럼 설계하고(밀도 — 셋업/페이오프·색코드·콜드오픈·도덕 변곡), 드라마처럼 끊어라(리텐션 — 클리프행어·재계약·관계 자산)."**
→ *적용:* S1-Q4(시청 환경) → S13(프레임)·S15(호흡)·S21(화각 예산)의 기본값.

## 카드 K — 4대 구조 모델 정렬 (M1 하이라이트) 📚 강의: 슬라이드20·23
- 시드필드 3막 / 맥키 5부 / 보글러 12단계 / 스나이더 15비트 — **전환점이 전부 25%·50%·75%에 정렬된다.** 촉매=촉발사건=도발적 사건: 같은 것의 다른 이름.
- **하나만 깊이 알면 나머지는 번역이다.** 어떤 분량이든 총 러닝타임의 25/50/75에 전환점만 박으면 어느 모델로 봐도 맞는다.
- 300초 환산: 75초(구성점1) / 150초(미드포인트) / 225초(구성점2). **숏폼 = 1막을 극단적으로 짧게 만든 3막(발단을 0초로).**
→ *적용:* S4 골격. 사용자가 특정 프레임워크를 좋아하면 그걸로 말하고, 뼈대는 동일하게 유지.

## 카드 L — 7비트 v2 · 트랙 · 사이다 회계학 (M4) 📚 강의: 슬라이드59~66
- **7비트 v2** = 정통 3막을 300초에 접고 비트마다 작법 원리를 끼운 것(매핑표는 `01` S5). 마이크로 3막(굴욕→떡밥→직전 끊기)의 완결 확장판.
- **트랙 = 전제의 방향. 섞으면 둘 다 죽는다(하나만):**
  | 트랙 | 대상 | 엔진 | 카타르시스 | KPI |
  |---|---|---|---|---|
  | 로판 | 여성향 | 오해→재회→집착·헌신 | 사랑받음+신분상승 | 좋아요 |
  | 사이다 | 남성향 | 굴욕→정체노출→응징 | 무시한 자들의 굴복 | 좋아요 |
  | 감동·공감 | 중성향 | 상처→이해→화해 | 눈물·공감 | **댓글**(토론형) |
- **정체 격차**: 겉신분↔실제정체의 격차가 클수록 반전이 세다. 표층(신분) 위에 심층(내면 — "그래서 저 표정이었구나")을 겹치면 재시청이 생긴다.
- **사이다 회계학(감정의 적립→환급)**: ①선입견 심기(관객도 같이 속인다) → ②갑질(분노 **적립**) → ③균열(단서) → ④반전(일시불 **환급** = 카타르시스). **적립 없는 환급(뜬금 반전)은 아무 감정도 못 만든다 — 앞에서 열심히 짓밟아야 뒤가 시원하다.**
- **스펙터클이 아니라 감정의 명료함**: "이 작품이 주는 감정이 한 문장으로 안 나오면 실패다. 화면이 아무리 예뻐도." (시학 6요소의 현대 실증 — 볼거리는 꼴찌.)
→ *적용:* S5-D(7비트), S2(트랙·전제), S5 감정 회계 점검.

## 카드 M — 명작 공통 문법 6 · 그대로 가져올 것 7 (M3 종합) 📚 강의: 슬라이드49~50
> 장르가 극단적으로 달라도(변신 비극 / 휴먼 구원 / 타임슬립 스릴러) 이 여섯은 같았다. **원리만 차용 — 표면 복제 금지.**
- **공통 문법 6**: ①결과부터 보여주고 되감기(질문을 '무엇'→'어떻게'로) ②정보 비대칭(미스터리보다 서스펜스 — 관객에게만 진실을 먼저) ③셋업/페이오프를 신뢰 자산으로(하찮게 심고 같은 앵글로 회수) ④명대사 극도 희소(힘은 빈도가 아니라 배치 간격) ⑤정점에서 음악 빼기(음악은 감정을 만드는 게 아니라 끝난 뒤 정산) ⑥형식은 고정, 내용은 예측 불가(반복 포맷이 변화를 재는 자).
- **그대로 가져올 것 7**: ①결과 선노출(안 어울리는 오브젝트 3개 병치+되감기) ②2초 셋업→같은 앵글 회수(AI: 동일 소품 ref 락) ③3회 절제→1회 폭발(몸의 행동으로) ④정점 무음(단일 사운드만) ⑤결말 정보 선지급(무표정 컷이 알아서 아파짐 — AI 표정 연기 대체) ⑥장치는 소품 하나에 규칙 셋(최소 판타지=최대 리얼리즘 보증, 규칙은 설명 말고 검증으로) ⑦승리 뒤 잔맛 5초(해결이 만든 새 대가를 남겨라). + 굴욕 선불(초반 30초 공감 자본) + 로맨스는 생활 비트로.
→ *적용:* S4(오프닝)·S5(비트 주입)·S7(대사·정보 설계)·S21~S23(앵글·색·소품).

## 카드 N — 스포일러 훅 · 이중 자산 · 훅 3종 (M4 표층) 📚 강의: 슬라이드54·62~63·68
- **스포일러 훅**: 결말을 제목에서 깐다. 제목=로그라인=카타르시스 예고편. 시청자는 결말이 "어떻게 일어나는지"를 보러 온다. 구어체+?!… 고빈도 토큰(정체·무시·재벌·계약·환생·복수). ❌"어느 청소원의 이야기"(정보 0) ⭕"청소원 무시했더니 회장 손주였다"(굴욕+격차+카타르시스 예고).

## 카드 O — 비전 디렉터의 원칙 5 (🎬 비전: Part 1 — 기획의 본질)
> 두 번째 강의(AI 비전 디렉팅)의 기획 철학. STAGE 1의 태도이자 STAGE 2~4의 판정 기준.
- **의도가 없으면 감독이 아니다**: "AI가 10초 만에 만든 영상에 당신의 의도가 없다면, 당신은 감독인가, AI의 첫 번째 관객인가?" 기술은 How, 인간은 What·Why. **AI는 캔버스를 채우려 하고, 감독은 캔버스를 비우려 해야 한다.**
- **몽타주(배치가 의미다)**: A+B=C — 의미는 이미지가 아니라 배치에서 나온다(쿨레쇼프). 개별 컷 퀄리티보다 컷 사이의 관계 설계가 먼저다.
- **푼크툼(결핍을 기획하라)**: AI는 평균(스투디움)을 학습해 매끈하고 영혼 없는 화면을 만든다. 눈을 즐겁게 하면 스투디움, 가슴을 찌르면 푼크툼 — **완벽을 버리고 결핍·상처·이물감 1개를 심어라.** 시간의 압력("그것이 거기 있었다")이 결합되면 가장 강력하다.
- **Atmosphere(What이 아니라 How)**: 객체 나열은 묘사다. 공간의 온도·습도·밀도·긴장을 지시하라. 몽타주는 관객을 설득하고, Atmosphere는 관객을 매혹한다.
- **오프스크린(보여주지 않는 힘)**: 화면 밖 공간은 서스펜스의 영역. 위협은 직접 그리지 말고 '화면 밖을 의식하는 행동'으로 — AI 약점 회피와 긴장 극대화를 동시에.
→ *적용:* S1(마인드셋)·S6(몽타주 배치)·S7(오프스크린)·S8(푼크툼 채집)·S23(푼크툼·Atmosphere 소품화)·S27(무브의 동기). 렌즈·조명·미장센·무브의 실행 조각은 `03`·`04`·`06`.

# 4부 · 용어 사전

- **로그라인**: 이야기를 주인공·목표·장애물·역설로 압축한 한두 문장. 곧 제목·후크의 씨앗.
- **전제(Premise)**: 이야기가 증명하려는 한 문장(원인→결과).
- **지배 아이디어(Controlling Idea)**: "가치 + 원인"으로 쓴 주제문. 절정에서 증명됨.
- **구성점(Plot Point)**: 이야기를 다른 방향으로 트는 큰 사건(1막 끝·2막 끝).
- **미드포인트**: 2막 중간의 판 뒤집기(거짓 승리/패배).
- **급전(Peripeteia)**: 상황의 급반전. **인식(Anagnorisis)**: 진실의 깨달음. 둘이 겹치면 **카타르시스**.
- **Want / Need**: 외적 목표(플롯) / 내적 진실(주제). **Lie**: 잘못된 신념. **Wound**: 그 신념을 심은 상처.
- **아크(Arc)**: 인물의 내적 변화 궤적(긍정/타락/평면/비극).
- **성격묘사 vs 진짜 성격**: 겉으로 보이는 것 vs 압박의 정점에서 하는 선택.
- **서브텍스트**: 대사의 겉뜻과 속뜻의 낙차.
- **극적 아이러니**: 관객은 알고 인물은 모르는 정보 격차(서스펜스의 원천).
- **셋업/페이오프**: 미리 심고(setup) 나중에 회수(payoff)하는 장치.
- **비트(Beat)**: 씬보다 작은 서사 단위. **비트시트**: 이야기를 비트로 나눈 표.
- **8시퀀스**: 3막을 8개 미니무비로 나누는 프레임.
- **데마이(demai/얕은 심도)**: 망원·개방조리개로 배경이 보케로 녹는 클로즈업.
- **OTS**: 오버더숄더. 인물 어깨 너머로 상대를 잡는 대화 화각.
- **네거티브필**: 그림자 쪽에 흑색 반사판을 둬 얼굴 한쪽을 어둠에 묻는 조명.
- **로우키/하이키**: 강대비 어두운 조명 / 연대비 밝은 조명.
- **색코드**: 인물·공간마다 고정색으로 감정·도덕 상태를 대사 없이 전달.
- **Voice Sheet**: 인물별 락된 음성 프로파일(ElevenLabs voice_id + settings). 전 씬 강제.
- **i2v**: image-to-video. 정지 이미지를 시작 프레임으로 영상 생성.
- **pace(호흡)**: 씬의 리듬. 타이트(짧은 컷·빠른 무브) / 슬로우(긴 컷·홀드).
- **시청 계약**: 매체가 관객과 맺는 암묵 계약. 영화=선불(인내 자본), 드라마=매 순간 재계약(숏폼은 3초).
- **콜드오픈**: 설명 없이 사건·수수께끼로 여는 오프닝. 발단 0초(인 메디아스 레스).
- **핀치포인트**: 2막 중 37.5%·62.5%에서 적대세력을 상기시키는 압박 컷.
- **정체 격차**: 겉으로 보이는 신분과 실제 정체의 낙차. 클수록 반전(급전)이 세다.
- **마이크로 3막**: 굴욕→떡밥→직전 끊기의 90~150초 리텐션 사이클(숏폼).
- **이중 자산**: 본편(전환 엔진)과 1분 훅(조회 엔진)을 한 소스에서 두 벌로 운용.
- **스포일러 훅**: 결말을 제목에서 까서 '어떻게'를 팔게 만드는 제목 문법.
- **사이다 회계학**: 감정의 적립(굴욕·분노)→환급(반전·카타르시스) 구조. 적립 없는 환급 = 뜬금포.
- **오브젝트 POV**: 사물 안/밑에서 인물을 올려다보는 광각 로우앵글. "이 사물이 중요해진다"는 신호.
- **사운드 브리지**: 화면과 소리를 다른 공간에 두는 편집 — 소리의 방향만으로 감정을 만드는 장치.
- **가짜 리버스샷**: 두 인물을 한 프레임에 넣지 않고 단독 CU 맞교차로 대화처럼 읽히게 하는 편집(AI 일관성 리스크 회피).
- **의상 색 아크**: 인물의 도덕·감정 변화를 의상 색 3단계로만 전달하는 무의식 채널.
- **품질 모드(MODE)**: S0-B에서 정하는 크레딧 철학. QUALITY(다안·마스터 직행) / ECO(초벌→컨펌분만 고화질).
- **푼크툼/스투디움**: 스투디움=교양적 정보(잘 만든 화면), 푼크툼=보는 이를 찌르는 우연한 결핍의 디테일. AI는 스투디움에 강하므로 푼크툼은 기획으로 심는다.
- **Atmosphere(공기감)**: 화면의 시각 정보 너머 공간의 정서적 공기·온도·밀도. What이 아니라 How로 지시.
- **오프스크린**: 화면 밖 공간. 보여주지 않음으로 만드는 서스펜스.
- **Z축 레이어링**: 전경(흐림)–중경(인물)–후경으로 깊이를 설계. 전경 흐림 = 훔쳐보기 몰입.
- **프레임 속 프레임**: 문틈·창·거울 안에 인물을 가두는 구도 — 고립·관음.
- **다다미 샷**: 앉은 눈높이(60~90cm) 고정 카메라 — 동등하게 관조하는 시선.
- **랙 포커스**: 초점을 A→B로 옮겨 주도권·생각의 이동을 대사 없이 보여주는 기법.
- **돌리 줌**: 카메라 후진+줌인 동시 — 배경만 왜곡되는 공황·현실 붕괴의 시각화.
- **틸앤오렌지**: 피부톤(오렌지)의 보색인 청록으로 배경을 감아 인물을 분리하는 표준 배색.
