# 04_video_S25-S30.md — STAGE 4 · 영상

> 입력 = 씬별 고화질 본 이미지(캐릭터 락) + `SCENARIO_BIBLE`(대사·pace) + Voice 슬롯. 출력 = 씬별 i2v 클립(캐릭터·음성 락 · No-BGM/SFX only) + 버전 관리 콘솔 + 대사·SFX 오디오.
> **두 절대 규칙이 이 STAGE를 지배한다:** ① **모든 영상은 BGM 절대 금지, 효과음만.** ② **한 인물의 음성은 전 씬에서 동일**(음성 일관성 최우선). 둘 중 하나라도 깨지면 그 클립을 폐기·재생성한다.

## GATE S25 — 엔진 · 화질 선택

**왜:** 드라마 AI 영상 엔진과 화질을 먼저 잠근다. (사용자 요구: "클링3.0 과 시댄스 2.0 중 선택… 화질도 720p, 1080p 중 선택.")

### Q25-1. 영상 엔진 (객관식)
| 선택 | 엔진 | 강점 | 경로 |
|---|---|---|---|
| A. **클링 3.0(kling3_0)** | 인물 연기·자연스러운 모션·물리 | 대사·감정 연기 씬 | Higgsfield MCP/CLI `kling3_0` |
| B. **시댄스 2.0(seedance_2_0)** | 카메라 무브·다이내믹·멀티샷 | 인서트·액션·전환 씬 | Higgsfield MCP/CLI · Replicate `system/generate_seedance.mjs` |
| C. 씬 성격별 혼용 [추천] | 대사=클링 / 인서트·액션=시댄스 | 밸런스 | 씬 카드의 `[대사|인서트]`로 자동 배정 |

### Q25-2. 화질 (객관식 — MODE가 기본값을 정한다)
- A. **720p**(빠름·저비용, 초벌·대량) / B. **1080p**(마스터 품질)
> **MODE 훅:** QUALITY = **1080p 직행** + 감정 피크 씬 2테이크. ECO = **2패스: 720p 초벌 전 씬 → 컨펌 컷은 1순위 `video_upscale`(Magnific)로 1080p화(테이크 보존 — i2v는 시드 고정이 없어 '재생성'하면 컨펌한 테이크와 다른 결과가 나온다), 업스케일 품질 미달 컷만 1080p 재생성+재컨펌.** (모드 기본값을 제시하되 사용자가 오버라이드 가능.)

### Q25-3. 비율·길이
- 비율 = STAGE 2의 프레임(가로 16:9 / 세로 9:16) 고정.
- 컷 길이 = 씬 `pace`에서 자동(타이트 1.5~2.5s / 슬로우 4~8s). S27에서 씬별 확정.
- **⚠ duration 변환 규칙:** pace의 목표 컷 길이는 **편집 트림 기준**이지 생성 duration이 아니다. 엔진은 초단위 최소값이 있다(예: seedance 4s, kling 3s — 호출 전 `models_show`로 확정). **생성 duration = max(pace 목표, 엔진 최소값)**으로 뽑고, 타이트 컷의 실제 1.5~2.5s는 **S32 편집 트림**으로 만든다(목표 컷 길이는 `video_prompts.json` 메타로 보존 — 트림 여유를 위해 액션을 클립 앞쪽에 배치하도록 프롬프트).

> **비용 미리보기:** `get_cost`(또는 CLI `generate cost`)로 씬수×화질 크레딧을 계산해 `balance`와 함께 승인받는다. 동시 한도(예: 8) 준수 — 배치는 백그라운드 에이전트.

**산출물:** 엔진(A/B/C) · 화질 · 비율 · (2패스 여부).

## GATE S26 — 음성 일관성 락 ★ (Voice Sheet 완성)

**왜:** 사용자 최강조 — **"캐릭터 시트에 맞는 각각의 캐릭터의 음성 특성을 샘플 영상으로 정하거나 기존 음성을 첨부해 활용하고, 이후 일관성을 유지."** 영상 엔진(클링/시댄스)은 호출 간에 목소리를 '기억'하지 못한다. 그래서 **인물별로 하나의 음성을 확정·박제(Voice Sheet)해, 전 씬에 그 음성만 강제**하는 방식으로 일관성을 만든다. (모델의 기억이 아니라 **파이프라인이 강제**한다 — 이게 유일하게 안정적인 방법.)

### 26-1. 음성 소스 선택 (객관식 — 인물별)
| 선택 | 방식 | 절차 |
|---|---|---|
| A. **샘플로 정하기** | 후보 음성 몇 개로 짧은 샘플을 만들어 고름 | 26-2 |
| B. **기존 음성 첨부** | 사용자가 이미 가진 음성 파일 사용 | 26-3 |

### 26-2. (A) 샘플로 정하기
1. 인물의 목표 음색(S20)에 맞는 **후보 voice를 고른다**(ElevenLabs 보이스 라이브러리 또는 프리셋).
2. 각 후보로 그 인물의 **대표 대사 1~2줄 TTS 샘플**을 생성(같은 대사·같은 감정 지시로 — 변수 하나만 바꿔 비교).
3. 대표 씬 이미지 1장 + 각 샘플로 **짧은 립싱크 테스트 영상**을 만들어 입 모양·톤 궁합을 본다. (QUALITY 기본 / ECO 생략)
4. 사용자가 하나 선택 → 그 **voice_id를 Voice Sheet에 락**.
> **MODE 훅:** QUALITY = 후보 **4개** + 립싱크 테스트 영상. ECO = 후보 **2개** · TTS 샘플만(립싱크 테스트 생략). (모드 기본값을 제시하되 사용자가 오버라이드 가능.)

### 26-3. (B) 기존 음성 첨부
1. 사용자가 음성 파일(mp3/wav)을 제공 → 경로·용도 확인(4종 프리뷰에 명시).
2. ElevenLabs **Instant/Professional Voice Clone**으로 그 음성을 클론 → 생성된 **voice_id를 Voice Sheet에 락**.
3. 짧은 대사로 클론 품질을 확인(원음과 톤 일치) 후 확정.

### 26-4. Voice Sheet 확정 (인물별 락)
```
[VOICE_SHEET · {인물}]
voice_id: <락된 ElevenLabs voice_id>
voice_settings: { stability, similarity_boost, style }  # 인물 톤에 맞춰 고정
목표 음색: <S20 자유서술>
비고: 전 씬 이 voice_id만 사용. 변경 금지(변경 시 새 버전으로 분기).
[저장] projects/narrative/{name}/v{날짜}/voice_sheets/{인물}.json
```

### 26-5. 일관성 강제 규칙 (전 씬 적용)
- **대사 오디오는 항상 이 voice_id로 생성**하고 영상에 얹는다(포스트 더빙). 영상 클립 자체 오디오는 규칙 0-[B]대로 **SFX only**.
- 립싱크가 필요한 대사 씬: 락 음성 오디오를 **입력/가이드로** 주거나(엔진이 지원 시), 지원 안 되면 **무음 영상 생성 → 락 음성으로 후반 더빙 + 립싱크 컷 회피 화각**(OTS·3/4·리액션, S21).
- **드리프트 감시:** 씬 결과의 목소리가 락과 다르게 들리면 그 씬을 폐기하고 락 voice로 재생성(규칙 7).

> **왜 후반 더빙을 기본으로 두나:** 영상 엔진이 매 호출 새 목소리를 만들면 인물 음색이 씬마다 흔들린다. 락된 단일 voice_id로 오디오를 따로 만들어 얹으면 **음색이 물리적으로 100% 동일**해진다. 이게 "음성이 변경되지 않고 일관성 유지"의 확실한 구현이다.

**산출물:** 인물별 Voice Sheet(락된 voice_id + settings). 캐릭터 시트에 병합.

## GATE S27 — 씬 영상 프롬프트 설계 (호흡 · 캐릭터 · 음성 락 · No-BGM)

**왜:** 정지 본 이미지를 '움직이는 컷'으로. 호흡(pace)이 카메라 무브와 컷 길이를 정한다.

### 27-1. 프롬프트 조립 (씬별)
```
규칙0[B](No-BGM/SFX only · 캐릭터·음성 락)  ← 반드시 맨 앞
+ DRAMA_VID_ENHANCE(06)
+ start-image = 그 씬의 본 이미지(캐릭터 락된 고화질)
+ 카메라 무브(pace 기반, 아래)
+ 씬 동작·감정(SCENARIO_BIBLE)
+ 생성 duration(Q25-3 변환 규칙: max(pace 목표, 엔진 최소값) — 타이트 컷은 편집 트림 전제, 액션을 클립 앞쪽에)
+ (대사 씬) 화자·대사·감정 → 락 voice로 오디오 별도 생성(26-5)
```

### 27-2. 호흡별 카메라 무브 (pace → 무브)
| pace | 카메라 | 컷 길이 |
|---|---|---|
| ⚡ **타이트** | 빠른 단일 무브(푸시인·휩팬·핸드헬드·크래시줌) + 매치컷 연결 | 1.5~2.5s |
| 🌊 **슬로우** | 느린 무브 또는 홀드(천천한 달리·미세 오빗·정지 + 미세표정) | 4~8s |
> **반전·감정 정점 컷**은 슬로우 홀드(표정 정보) 권장 — 명작 원리(절제→폭발). 정면 온-액시스는 이 리액션 컷에만. **무표정 홀드**(S21)가 결말 선지급과 결합하면 최소 모션으로 최대 감정이 난다(AI 표정 연기 불안정 회피).
> **정점 무음 원리** 📚 강의: 슬라이드49: 이 파이프라인은 원래 No-BGM이지만, **감정 최고점에서는 SFX마저 걷어내고 단일 사운드(숨·발소리·정적)만** 남기는 지시를 프롬프트·S30 믹스에 넣는다 — 침묵 자체가 패턴 파괴 훅이다. 직후 컷에서 사운드 복귀.

### 27-3. 무브먼트의 동기 사전 — 카메라는 왜 움직이는가 (🎬 비전: Part 5)
> **"카메라를 1인치라도 움직이려면 그만한 이유가 있어야 한다."** 무브는 장식이 아니라 심리 트리거다. 씬의 감정에서 무브를 고르고, **"Move"가 아니라 구체적 동사(tremble·glide·soar)로** 명령한다. (프롬프트 조각 = `06` [무브 동기 사전])

| 무브 | 심리 | 언제 |
|---|---|---|
| **푸시인**(slow push-in) | "이 사람 말을 잘 들어라" — 내면 진입·감정이입 | 결심·고백·반전 직전 |
| **풀아웃**(pull back to reveal) | 인물을 두고 떠남 — 고립·허무·상황 종료 | 엔딩·상실 |
| **리빌 샷**(slide/truck reveal) | 가려져 있던 정보의 공개 — 서스펜스→해소 | 반전·공간 공개 |
| **랙 포커스** | 초점 A→B = 주도권·생각의 이동 | 대사 없는 반전·관계 전환 |
| **돌리 줌**(dolly out+zoom in) | 배경만 왜곡 — 공황·현실 붕괴 | 충격의 순간(절제해서 1회) |
| **팬/틸트** | 좌우 훑기=관계 이동·공간 소개 / 틸트업=상승·위압, 틸트다운=하강·현실 직시 | 소개·전환 |
| **롤** | 지평선 붕괴 — 착란·혼돈 | 심리 붕괴 |
| **핸드헬드** vs **스테디캠/짐벌** | 날것의 현장감·불안 vs 물 흐르는 우아함·신의 시선 | 리얼 vs 몽환 |
| **스피드 램핑** | 슬로모=찰나의 감정 확대경 / 정지+오빗(불릿타임)=전지적 탐색 / 리버스=후회·꿈의 논리 | 액션 정점·초현실 |
- **렌즈 × 속도 물리학**: 속도감은 피사체가 아니라 렌즈가 만든다 — **광각 = 과장된 속도**(추격·액션), **망원 = 제자리걸음**(필사적이지만 벗어날 수 없는 악몽). 같은 달리기도 렌즈로 정반대 감정이 된다.
- pace와 결합: 타이트 씬의 무브는 이 사전에서 빠른 것(푸시인·휩팬·핸드헬드), 슬로우 씬은 느린 것(슬로우 푸시인·풀아웃·홀드)을 고른다. **동기 없는 무브 금지.**

### 27-4. 캐릭터 락 강제
- 규칙 0-[B]·[C]: start-image가 캐릭터 시트 락 이미지이므로 외관은 유지되나, 프롬프트에도 "match the character sheet, do not drift the face/voice" 명시. 인물 여럿이면 각자 시트 일치.

**산출물:** 씬별 영상 프롬프트(카메라 무브·길이·대사 매핑 포함) — `video_prompts.json`.

## GATE S28 — 씬 영상 배치 생성 (i2v)

### 28-1. 실행 절차 (검증된 순서)
1. **업로드**: 본 이미지(≤엔진 상한·용량 확인, 필요 시 다운스케일) → `media_upload`→PUT→`media_confirm`. (Replicate 경로는 스크립트가 처리.)
2. **생성**: 씬마다 `generate_video({model: kling3_0|seedance_2_0, prompt(규칙0[B]+무브+VID_ENHANCE), duration(pace), resolution(720p|1080p), aspect_ratio(프레임), medias:[{role:'start_image', value:media_id}]})` → job 수집.
3. **폴링·다운로드는 백그라운드 에이전트에 위임** — 동시 한도 준수, 완료분을 `videos/{engine}/{scene}.mp4`로.
4. **4종 프리뷰(승인 필수):** MODEL(클링/시댄스) · 해상도(720/1080) · **오디오=SFX only(No-BGM)** · 비율(프레임) + 씬별 요약 + start-image 파일명 + "규칙0[B]+DRAMA_VID_ENHANCE 주입됨" 표기.

> **CLI 경로(대량 편):** `higgsfield generate create kling3_0|seedance_2_0 --prompt "<규칙0[B] No-BGM + 무브 + VID_ENHANCE>" --start-image <씬이미지_경로> --duration <pace> --resolution 1080p --aspect_ratio <프레임> --wait` — 업로드·폴링 자동, 토큰 0. 결과 URL → 다운로드.

### 28-2. 에러 핸들링
- 동시 한도 초과=큐로 순차. · `fetch failed`=재시도. · NSFW/IP 오탐=표현 순화. · 프리셋 차단=`declined_preset_id` 리터럴 강제. · media TTL ~15분=재업로드. · 중단=디스크에 없는 씬만 재생성.

**산출물:** 씬별 i2v 클립(No-BGM, 캐릭터 락) `videos/{engine}/{scene}.mp4`.

## GATE S29 — 버전 관리 콘솔 HTML · 미세수정 루프

**왜:** 사용자 요구 — "한번에 마음에 드는 것이 나오지 않을 테니 버전별로 html에서 관리하고 디테일한 부분을 수정할수 있게 UI." 씬 영상은 여러 번 돌게 마련이니, **버전별로 쌓고 콘솔에서 골라 미세수정**한다.

### 29-1. 영상 버전 관리 콘솔 (`review_console/` --mode video 확장)
- **레이아웃**: 씬 카드 그리드, 카드마다 `<video autoplay muted loop playsinline>` 미리보기 + 프레임 비율 맞춤.
- **카드 구성**:
  - 씬번호 + `[대사|인서트]` + `pace` + 엔진 배지 + 화자
  - **버전 스택**: v1·v2·v3… 썸네일 나열, 클릭해 현재 채택 버전 선택(채택 = `results.json`에 최신 경로).
  - **수정 패널**:
    | 컨트롤 | 옵션 |
    |---|---|
    | 엔진 | 클링3.0 / 시댄스2.0 |
    | 화질 | 720p / 1080p |

## GATE S30 — 대사 · SFX 오디오 조립 (No-BGM)

**왜:** 규칙 0-[B]에 따라 영상 클립은 SFX only. 대사·효과음 오디오를 **락 음성으로** 정리해 각 클립에 얹는다(편집 전 오디오 정돈). **BGM은 넣지 않는다.**

### 30-1. 대사 오디오 (락 음성)
- 대사 씬마다 화자의 **Voice Sheet voice_id**로 대사 TTS 생성(감정 지시 포함). — 인물별 음색 100% 동일 보장.
- 립싱크 필요 씬은 클립 타이밍에 맞춰 대사 길이 조정(속도·pause). 립싱크 회피 화각 씬은 오프-스크린/리액션 위로 얹는다.

### 30-2. 효과음(SFX) 레이어
- 씬 프롬프트에 지정한 디제틱 사운드(발소리·유리·문·숨)를 확보(생성 또는 라이브러리) → 클립에 배치. **음악 베드 금지.**

### 30-3. 클립별 오디오 얹기 (ffmpeg — 편집 전 정돈)
- 각 씬 mp4에 [대사(락 음성) + SFX] 트랙을 믹스(무음 영상 위에). BGM 트랙은 만들지 않는다.
- 산출물은 **오디오 포함 씬 클립** + **분리 오디오 스템**(대사/SFX 개별) — 프리미어에서 재조정 가능하게 둘 다 넘긴다.

> **음성 일관성 최종 확인:** 조립 전, 전 대사 클립의 목소리가 인물별로 동일한지(voice_id 일치) 점검. 하나라도 다르면 S26 락으로 재생성.

**산출물:** 오디오 포함 씬 클립 + 분리 스템(대사·SFX). → STAGE 5 편집 입력.
