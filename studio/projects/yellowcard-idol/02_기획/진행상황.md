## 외부 기획안(Master Plan) 검토 결과
**가져갈 것**
- 남녀 2인조: 1절 여자 랩, 2절 남자 랩, 3절 주고받기, 아웃트로 대화 → 노래 구조와 맞음
- "남자 후드티를 입은 여자" (가사 "내 후드티 가져가선 돌려주질 않잖아")
- 검정 + 형광 노랑, 가사는 코드로 화면 아래쪽에, AI 영상은 소리 없이 생성

**고칠 것**
1. 콘셉트 "Midnight Referees(둘이 한편이 되어 남을 심판)"는 v2의 누아르 실수로 돌아감 → 둘이 **서로** 카드를 내미는 장난스러운 밀당 경기로
2. 4번 장면의 노랑·검정 경고 테이프 = 범죄 현장 기호(기획에서 금지) → 축구장 흰 선·페널티 박스·스코어보드로
3. 이름 "RIA(리아)"는 실제 아이돌(ITZY 리아)과 한글 이름이 같음 → 새 이름 필요
4. 프롬프트 속 "Arcane style", "K/DA style" → 실제 작품·그룹 이름 삭제, 그림 특징으로 풀어 씀
5. 캐릭터 시트 단계가 없음 → 시트를 먼저 만들고 모든 컷의 기준으로
6. 입 모양으로 "Listen" 말하기는 AI가 잘 못 맞춤 → 손가락으로 렌즈 톡 + 글자로
7. 쇼츠 구간: 기획안은 61~95초. **123~164초(마지막 후렴 → 141초 RED CARD → "No. Game over.")** 안도 함께 검토

## 정한 것 (잠정 — 사용자 확인 전)
- 콘셉트: **「한밤의 경기」** — 비 갠 밤 동네 풋살장, 전광판 "0 : 0"
- 여자 멤버(Y): 스스로 심판 역. 큰 검정 후드티(그의 것) + 노랑 끈, 노란 카드. 테두리 빛 노랑
- 남자 멤버(W): 계속 카드를 받는 선수 역. 흰 티 + 회색 바람막이, 기타. 테두리 빛 흰색
- 색: 검정·흰·형광 노랑, 빨강은 141초 한 번만
- 그림체: 2.5D 셀 셰이딩 (3D·실사 바꾸기 문장도 준비함)

## 도구 사정
- 클라우드 세션은 네트워크 설정 때문에 외부 사이트(Kling, Midjourney, Ideogram, Krea, Suno, Higgsfield 등)에 접속이 막혀 있음(11/4 확인). 브라우저로 대신 생성하는 것은 지금 불가.
- 그래서 **프롬프트를 사용자가 직접 사이트에 붙여 넣는 방식**으로 진행. 열려면 환경 설정 Network access에서 해당 사이트를 허용해야 하고, 그래도 로그인 문제가 남음.
- 사용자가 말한 "지크" 사이트가 어디인지 확인 필요(주소·영어 이름). API가 있으면 그 주소만 허용해서 바로 쓸 수 있음.
