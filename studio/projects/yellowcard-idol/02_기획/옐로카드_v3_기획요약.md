# 작품 「Yellow Card」 뮤직비디오 — 1단계 기획 요약 (11/2 사용자 답 반영)

> 과제를 '작품'으로 하기로 함(11/2). 사용자가 만든 Suno 곡 「Yellow Card」(peace_shiny, 164초, 약 98 BPM) + 기존 v2 코드(GPT 제작)를 받음. "기존 코드가 많이 아쉬워" → 새로 만든다.

## 기존 v2를 보고 찾은 문제 (위에서부터)
1. **방향(대의)이 노래와 어긋남**: 가사는 *밀당하는 상대에게 축구 심판처럼 경고 카드를 주는* 장난스럽고 자신만만한 연애 노래(어깨 스치는 척, 물결표 문자, 후드티, "스코어는 동점, 다음 골은", "경고 두 장이면 red"). v2는 비 오는 밤 도시 + 범죄 현장 테이프 + 어두운 실루엣이라 **누아르·범죄물**처럼 읽힘.
2. **이야기를 끄는 그래픽 하나가 없음**: LP판·신호등·도시·테이프·실루엣이 번갈아 나올 뿐, 노래 제목인 "노란 카드"가 주인공이 아님.
3. **화면이 어둡고 정적**: 164초 내내 같은 어두운 도시 배경, 노랑은 작은 점으로만. 취향 기록의 "긴박감·흑백 + 형광 한 색·글자가 그래픽" 과 반대.
4. **글자가 작고 평범**: 왼쪽 위 작은 자막. 후렴 "yellow card, yellow card"가 화면을 터뜨리지 못함.
5. **실루엣 그림**: 얼굴을 가리느라 덩어리처럼 뭉개져, 사람도 그래픽도 아닌 어중간한 모양.

## 사용자 답 (11/2)
- 방향: 노란 카드 주인공 + 축구 경기 비유는 좋음, 단 **어두운 밤·도시 분위기는 유지** → 밤 도시 위에서 노란 카드만 형광으로 빛나는 화면.
- 사람: **실루엣을 코드로** → 사진 실루엣(덩어리) 대신 코드로 그린 두 사람(나: 긴 머리·노란 테두리 빛 / 너: 짧은 머리·흰 테두리 빛). 관절 각도로 자세를 바꿔 어깨 스침·다가옴·카드 들기를 직접 연기. 시험 화면: `시험/test_frame.png`

## 대의
**노란 카드 한 장이 2분 44초의 밀당 경기를 끌고 가는 세로 뮤직비디오.** 가사 속 축구 경기 비유(경고 · 선 · 스코어 · 레드카드 · 게임 오버)를 화면의 규칙으로 삼는다.

## 차별점
- **주인공 = 노란 카드 한 장**(도형 하나가 이야기를 끈다): 카드가 문자 말풍선 → 하트 두 번 → 후드티 → 경기장 선 → 스코어보드 → 레드카드로 모양을 바꾸며 장면을 잇는다.
- **코드 실루엣 두 사람**: 얼굴 없이 검은 몸 + 한쪽 테두리 빛(나 노랑 / 너 흰색). 밤 도시 거리 위에서 스치고, 다가오고, 가운데 흰 선을 넘으려 한다 → 가사 내용이 움직임으로 보임.
- **색 규칙**: 검정 + 흰색 + 형광 노랑 하나. **빨강은 141초 "red card" 딱 한 번**(반전), "no, game over" 에서 다시 노랑으로.
- **글자가 그래픽**: 후렴 "YELLOW CARD"는 화면 가득 큰 글자 띠로 박마다 찍힘, 한국어 가사는 카드·말풍선·전광판 안에.

## 노래 구조 (받아쓰기 + 음량으로 찾음)
| 구간 | 시간 | 화면 덩어리 (안) |
|---|---|---|
| 인트로 | 0~9 | 검정 위 휘슬 한 번 → 카드가 뒤집히며 등장 "Watch your step" |
| 1절 | 9~49 | 두 점의 밀당: 어깨 스침, 물결표 문자, 하트 두 번, 후드티 / "첫 번째 경고야" |
| 프리 코러스 | 49~66 | "한 번만 더 선을 넘으면" — 선 하나가 화면을 가로지르고 점이 다가옴, 빌드업 → 멈춤 |
| 후렴 1 | 67~90 | YELLOW CARD 큰 글자 띠, 카드가 박마다 찍힘, "출입 금지 구역" |
| 기타 · 2절 | 90~118 | 스코어보드 "동점", 템포가 꼬이는 화면, "경고 두 장이면 red" |

## 완료 조건
1. 1080×1920 세로, 30fps, 음원 그대로(길이·음 변경 없음)
2. 가사가 들리는 순간에 맞춰 글자·그림이 찍힘(받아쓰기 시각 기준, 틀린 받아쓰기는 사용자 원본 가사로 바로잡음)
3. 노란 카드가 처음부터 끝까지 한 번도 사라지지 않고 모양을 바꿔 이어짐
4. 빨강은 반전 한 번뿐, 그 외엔 검정·흰·노랑만
5. 2-3 세 가지 확인 통과(얌전하지 않음 · 끝까지 힘 유지 · 통째로 한꺼번에 바뀌지 않음 — 단 반전 한 번은 의도)
6. 20초 맛보기(후렴 1 앞뒤) → 확인 → 전체 → 다른 눈 검수

## 하지 않을 것
- 실사 얼굴·AI 생성 인물, 실존 축구 선수·팀·리그 로고
- 음원 손대기(속도·음정·자르기)
- 범죄 현장 테이프·사이렌 같은 범죄물 기호 (밤 도시 분위기는 유지)

## 사용자 답 2 (11/3) — 사람은 '암시'로
