## 3. 10화 뼈대 안 — "누가 읽습니까?"
1. **훅(끝 먼저):** 파쇄기에 종이 더미가 빨려 들어감 → 교사들이 둘러앉아 학생 글을 놓고 토론 → 굳은 교감. 제목 예: "교장이 보고서를 다 없앴다"
2. **교무실 아침:** 책상마다 결재판·계획서·결과보고서·상장 공적조서·종이 동의서 더미(화면). 교감 "곧 정정 공문 와요."
3. **다해의 첫 질문 (사이다):** 다해가 보고서 하나를 들고 "이 보고서, 누가 읽습니까?" → **교감 서랍을 열면 뜯지도 않은 결과보고서 더미**(2화 '반려 6번' 보고서도 있음 = 인과를 화면으로).
4. **규칙은 짧게(대사 1~2줄 + 화면):** "읽는 사람이 없는 종이는 없앱니다." 화면: 계획서 10장 → 1장, 결과보고 → 사진 3장, 상장 공적조서 칸에 빨간 줄, 종이 동의서 → 폰 링크.
5. **그 시간에 (진짜 경영):** 수요일 오후 '수업 이야기 시간' — 교사들이 9화의 손글씨 보고서·AI 보고서를 놓고 "AI가 대신 못 쓰는 수행평가는 어떻게 만들까" 토의. 정우가 처음으로 말을 꺼냄. (9화 문제를 10화가 '교육'으로 풀어 줌)
6. **교감 음모(계속):** 교감이 몰래 종이 결재 대장을 다시 만들어 이사장에게 "교장이 보고를 다 없앴습니다" 전화 → (후보 A) 교육청에서 '학교 가짜 일 줄이기' 공문이 내려와 교감 쪽이 머쓱 / (후보 B) 이사장이 대답 대신 "…그 빨간 만년필 말인데"(⑦ 착각 균열로 이어짐)
7. **끝:** 다해 무표정 얼굴.
