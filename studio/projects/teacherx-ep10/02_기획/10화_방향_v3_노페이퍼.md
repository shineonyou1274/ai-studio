## 3. 10화 뼈대 안 — "누가 읽습니까?"
1. **훅(끝 먼저):** 파쇄기에 종이 더미가 빨려 들어감 → 교사들이 둘러앉아 학생 글을 놓고 토론 → 굳은 교감. 제목 예: "교장이 보고서를 다 없앴다"
2. **교무실 아침:** 책상마다 결재판·계획서·결과보고서·상장 공적조서·종이 동의서 더미(화면). 교감 "곧 정정 공문 와요."
3. **다해의 첫 질문 (사이다):** 다해가 보고서 하나를 들고 "이 보고서, 누가 읽습니까?" → **교감 서랍을 열면 뜯지도 않은 결과보고서 더미**(2화 '반려 6번' 보고서도 있음 = 인과를 화면으로).
4. **규칙은 짧게(대사 1~2줄 + 화면):** "읽는 사람이 없는 종이는 없앱니다." 화면: 계획서 10장 → 1장, 결과보고 → 사진 3장, 상장 공적조서 칸에 빨간 줄, 종이 동의서 → 폰 링크.
5. **그 시간에 (진짜 경영):** 수요일 오후 '수업 이야기 시간' — 교사들이 9화의 손글씨 보고서·AI 보고서를 놓고 "AI가 대신 못 쓰는 수행평가는 어떻게 만들까" 토의. 정우가 처음으로 말을 꺼냄. (9화 문제를 10화가 '교육'으로 풀어 줌)
6. **교감 음모(계속):** 교감이 몰래 종이 결재 대장을 다시 만들어 이사장에게 "교장이 보고를 다 없앴습니다" 전화 → (후보 A) 교육청에서 '학교 가짜 일 줄이기' 공문이 내려와 교감 쪽이 머쓱 / (후보 B) 이사장이 대답 대신 "…그 빨간 만년필 말인데"(⑦ 착각 균열로 이어짐)
7. **끝:** 다해 무표정 얼굴.

## 5. 사람 마음(심리)으로 본 노페이퍼 — 사장님 11/24 "인간의 심리에 대해서도 알면 좀 더 좋을 것 같아"

| 개념 | 뜻 | 10화에서 |
|---|---|---|

| 현상 유지 편향·손실 회피(카너먼·트버스키, 새뮤얼슨·잭하우저) | 바꿔서 얻는 것보다 잃는 게 두 배쯤 크게 느껴져 '하던 대로'를 고름 | 교사들도 처음엔 망설임("그래도 계획서는 있어야…"). 한 번에 다 없애지 말고 "한 달만 해 보고 다시 정합시다" |

| 파킨슨의 법칙 | 일은 주어진 시간만큼 늘어남 | 회의 15분 제한의 근거(11화 이후) |
| 자기결정이론(데시·라이언): 자율성·유능감·관계성 | 사람은 스스로 정하고, 잘한다고 느끼고, 함께할 때 움직임 | 다해가 규칙을 내려 주지 않고 **"없앨 종이는 선생님들이 고르세요"** → 교사들이 직접 파쇄기에 넣음(사이다를 교사들이 함) |
| 이케아 효과(내가 만든 것을 더 아낌) | 직접 정한 규칙을 더 지킴 | 위와 같음 — 정의로운 연설 금지 원칙과도 맞음 |
| 심리적 안전감(에이미 에드먼슨) | 틀린 말 해도 혼나지 않는다고 믿어야 회의에서 말함 | '수업 이야기 시간'에 아무도 말 안 함 → 다해가 먼저 "제 수업이 제일 별로였습니다"(실패 공개) → 정우가 처음 입을 염 |
| 학습된 무기력(셀리그먼) | 해도 안 된다는 경험이 쌓이면 시도를 멈춤 | 정우가 1부 내내 체념한 이유. 10화에서 처음 회복하는 모습 = 정우의 성장선 |

→ 이 표를 반영하면 3절 뼈대가 이렇게 바뀜(제안):
- 3번 "누가 읽습니까?" 뒤에 **"없앨 종이는 선생님들이 고르세요"** → 교사들이 하나씩 파쇄기로(훅 장면과 같은 화면).
- 교감이 머뭇거리는 교사들 앞에서 "감사 나오면 누가 책임져요?" → 다해 "교장이 집니다." (짧고 무표정, 사이다 한 방)
- 5번 토의에서 다해가 먼저 자기 실패를 말해 정우가 입을 엶.

### 10화에 넣는 방법 (제안)
- 다해의 핵심 한 줄(후보, 작가가 정함):
  - "이 종이들, 다 누구 책임인지 적는 칸만 있네요." (서류 클로즈업: '책임자: ___' 칸마다 교사 이름)
  - 교감 "감사 나오면 누가 책임져요?" → 다해 "교장이 집니다."
  - "선생님이 하고 싶은 수업이 아이들을 키운다면, 그걸 지키는 게 제 일입니다."
- 종이를 나누는 기준(화면): 서류마다 '책임자' 칸 → 교사 이름이면 파쇄기 / 교사를 지켜 주는 기록(안전점검 등)은 '작성: 교장·교감'으로 옮김.
- 체험학습은 따로 한 화(11~12화 안)로 아껴 둠 추천 — 다해가 인솔 계획서 '책임자' 칸에 교사 대신 자기 이름을 쓰고 직접 버스에 오름. 10화에는 체험학습 서류 한 장만 파쇄기 앞에서 멈칫(복선).
