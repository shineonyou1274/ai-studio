# 1화 편집 방향 v1 (2026-11-03)

사장님: "주인공 다해가 더 냉철하고 탁탁 꽂히는 발음에, 교감 입장에선 얄밉기도 하고 시청자는 통쾌한 느낌이면 좋겠다. 화면 전환은 굉장히 빠르게 진행되면 좋겠고, 음성 들어보니 살짝 밋밋해서 효과음·배경음이 필요할 때 적절히 들어가야 좋을 듯. 자칫 루즈할 수 있어."

## 1. 목소리
- 다해 다시 녹음 v2(9줄): 태그 cold·crisp·cutting·deadpan·slightly smug, stability 0.45, 문장을 마침표로 짧게 끊음("지적도상, 여기는. 학교 담장 안.").
- 편집에서 다해 대사만 1.08배(음높이 유지, 크레딧 0) → 말끝이 더 단단하게.
- 교감은 지금 그대로(거들먹 → 당황 → 굽신의 낙차가 통쾌함을 만듦).

## 2. 화면 전환 (빠르게)
- 컷 평균 2초 안팎. 대사 컷도 한 문장마다 앵글을 바꿈(다해 → 교감 반응 → 다해 손/만년필 인서트).
- 대사 사이 빈 숨은 0.15초까지 자름. 3초 넘게 같은 화면 금지.
- 전환: 휙(휩 팬) + "슉" 효과음, 크래시 줌(결정타 직전), 흰 번쩍임 2프레임(결정타 순간).
- 길이 목표: 3분 → 약 2분 30초로 줄어도 됨(빨라진 만큼).
