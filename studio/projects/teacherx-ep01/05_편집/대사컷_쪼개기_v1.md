# 대사 컷 쪼개기 v1 (2026-11-10) — "대사하는 동안 계속 같은 장면이면 지루하지 않을까"

원칙: **소리(녹음)는 이어 두고, 화면은 2~3초마다 바꾼다.** 말하는 얼굴은 입이 맞는 구간만 쓰고, 나머지는 반응·인서트·확대로 덮는다(AGENTS.md "교차 편집", 강의 정리 p.4 "3초마다 다시 붙잡기").

## 쓰는 재료 (크레딧 0 또는 거의 0)
1. **같은 영상 안에서 확대(펀치 인)**: 480p라 1.3배까지만. 문장이 바뀔 때 넓게 → 가깝게.
2. **듣는 사람 반응**: 이미 만든 영상의 '말 안 하는 구간' 재사용(교감 08 끝 굳은 얼굴 등) + 미리 보기 그림에 편집 움직임(A 방식).
3. **인서트**: 만년필·시계·결재판·폰·쪽지·경계석 그림(요소 그림/미리 보기 v2)에 천천히 줌.
4. 모자라면 **반응 컷만 따로 짧게 생성**(4초, 표준 12) — 묶음마다 견적에 포함해 승인받음.
