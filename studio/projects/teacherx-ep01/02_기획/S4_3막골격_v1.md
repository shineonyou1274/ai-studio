- 아이를 도구로 쓰지 않음: 우수사례 사진은 '아이 얼굴 없이 시만' — 다해가 직접 선을 긋는 장면으로 금기를 오히려 보여 준다.
- 사실 확인 필요(6-1절 ①): "교내 수업 장소 변경은 결재 대상이 아니다", "우수사례 제출 공문"은 학교·교육청마다 다르다. 실제 규정으로 단정하지 않고 **이 학교의 규정 / 인물의 대사**로만 쓴다. 대본 단계에서 표현을 다시 점검한다.
