# 교사X — S3 캐릭터 v1 (2026-11-01, 작성 중)

## 사장님 결정
- "일부러"의 이유(사장님 원문): "자신의 언니가 앞의 책임을 쓰고 사라져버린 과거의 교사. 무능하고 비겁한 관리자들과 학교의 비리 등 왜 언니가 사라졌는지 알아보기 위해.. 언니를 찾아보려고"
- 아크: 평면 아크 (교사X는 변하지 않고, 주변과 학교가 변한다)
- 적 구조: 회차 상대(우스꽝스럽게 지되 미화하지 않음) + 시즌 상대(책임을 떠넘기는 구조와 그 덕을 본 사람)

## 편집장 초안 — Want / Need / Lie / Wound
| 칸 | 내용 |
|---|---|
| Wound(상처) | 교사였던 언니가 결재받은 그대로 아이들을 인솔했는데, 사고가 나자 결재한 사람들은 빠지고 언니 혼자 책임을 지고 학교를 떠나 연락이 끊겼다. |
| Lie(세상이 믿는 거짓) | "규정대로 하고 결재받으면 학교가 지켜 준다." 언니가 믿었던 말. 교사X는 이 말을 믿지 않는다 — 평면 아크에서 거짓은 주변 인물(동료 계약교사·학교)이 품고 있고, 교사X가 깨 준다. |
| Want(시즌) | 언니가 왜 사라졌는지 진실을 밝히고 언니를 찾는다. |
| Want(회차) | 아이들에게 지금 필요한 수업을 한다. 허락은 받되, 책임은 결재한 사람에게 돌려준다. |
| Need | 언니가 진 짐을 혼자 다시 지지 않는 것(혼자 다 하던 교사X가 시즌 끝에 동료에게 일을 맡긴다 — 평면 아크 안의 작은 균열). |
| 스타일과 상처의 연결 | 교사X가 "규정을 제일 잘 읽는 사람"이 된 이유 = 언니를 무너뜨린 것이 바로 결재와 규정이었기 때문. 다시는 같은 덫에 걸리지 않으려고 모든 수를 미리 읽는다. |

## 사장님 결정 (추가)
- 언니: **살아 있고 스스로 숨었다.** 숨은 이유는 학교 비리와 이어져 있다. 시즌 끝에 찾아내는 것이 압승.
- 정체: **학교는 아무도 모른다.** 성이나 이름이 달라 알아채지 못한다. 시즌 중반에 정체가 드러나는 순간을 '정보 공개 + 처지 역전'이 한 컷에 겹치는 반전으로 쓴다.
- 주인공 성별: 여성("언니"). 편집장 확인 필요 없음.

## 편집장 메모
- 언니의 실종을 비극(죽음)으로 두지 않은 것은 실제 사건을 떠올리게 할 위험을 피하고, 사장님 금기 "적당한 타협 금지"와 사이다 톤을 함께 지키는 선택이다.
- 1화의 분량 배분: 회차 사건(꽃 피는 날의 결재)이 약 90%, 언니 떡밥은 마지막 클리프행어 한 컷. 시청자에게도 1화에서는 "일부러 왔다"까지만 보이고, 언니는 아직 보이지 않는다(정체 비밀 유지).

## 이름·방향 확정 (사장님 2026-11-02)
- 실명 **독고다해(獨孤多解)** — 별명 **독고다이**. ("독고다이가 또 독고다해 버렸네" 말장난은 아껴 쓴다)
- 방향: **합친 안, 오마주 없음.** 닥터X 표면 요소 전부 뺌 — 뒷배 매니저·과일/청구서 등장, "나, ~니까" 결정대사, 승리 뒤 단 음료 의식, 이름 '미지'.
- 유지: 업무경감 입찰제 + 최저가 낙찰 / 실력 = 언니의 일기장(학교 사정) + 대치동 일타 강사 경력(실력·돈) / 무기 = 국어식 어휘·비문 결정타(한 회 한 번, 빨간 만년필을 내려놓는 순간) / 승리 의식 = 은색 시계 보고 정시 퇴근.
- 언니의 성은 다해와 다르다(학교가 알아채지 못하는 이유).
- 조력자: 있으면 좋겠다. 후보(사장님) — ① 다해 덕분에 대학을 잘 간 사람 ② (다해 본인) 법 전공 후 언니 때문에 국어 교사로 바꿈.
- 조력자 관계(사장님 2026-11-02): 행정실 취업안은 뺌("월급이 적어 너무 별로"). **대치동 학원 시절 다해가 장학생으로 대학 등록금 정도를 도와준 사이.** 지금 이 학교에서의 자리는 결정 대기.
