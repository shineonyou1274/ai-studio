## 7비트 검증 3종
1. 첫 10초 안에 위기가 그림으로 보이나? → 예. 16:58 시계 + 교감 혼자 + 빈 보고서.
2. ③에서 심은 물건 = ⑤⑥에서 터지는 물건? → 예. 교감 폰(②③ 재단 문자 → ⑤ 마감 알림), 은색 시계(④ → ⑥), 이중결재(③ → ⑥). 벤치(⑥) → 일기장 사진(⑦).
3. 악역 1명? → 예. 교감.
