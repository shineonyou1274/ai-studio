# 교사X 4화 소재 두 가지 — 사실 정리 (2026-11-16, 편집장)

사장님 11/16: "학맞통이나 고교학점제 최성보 생각중". 이야기는 작가가 정합니다. 아래는 확인한 사실과, 이야기로 옮길 때 걸리는 점입니다.

## 1. 학맞통 (학생맞춤통합지원법)
| 사실 | 출처 | 상태 |
|---|---|---|
| 2026년 3월 1일 전면 시행. 2023년부터 시범 운영 | 한국교육신문(2026), 뉴시스 2026-02-12 | 확인 |
| 학교장 총괄, 교육청에 학생맞춤통합지원센터 설치, 지방공무원 241명 이상 증원 계획 | 뉴시스·트윅24 2026-02-12 | 확인(보도) |
| 교원단체 반발: "학교가 학생 복지까지 맡는다", 새 업무 부담 우려. 선도학교 교사는 행정업무 실제 경감·전문인력 확충 요구 | 한국교육신문 | 확인 |
| 법 조문(학교 안 전담 조직 이름, 담임의 역할 범위) | — | **확인 못 함** — 대본 전에 법령 원문으로 확인 |
- 이야기로 옮기면: "학생 한 명의 위기 지원이 전부 담임 한 사람에게 몰리는" 구조. 다해의 한 수는 '법이 정한 총괄·지원 체계로 돌려놓기'.
- 걸리는 점: 아이를 도구로 쓰지 않는다(바이블 금기). 위기 학생이 나오면 그 학생이 사건 해결의 소품이 되지 않게 해야 함.

## 2. 고교학점제 최성보 (최소 성취수준 보장지도)
| 사실 | 출처 | 상태 |
|---|---|---|
| 2025년 고교학점제 전면 도입. 미이수를 막기 위한 보충지도가 방과후·방학으로 몰려 교사 업무 과중 지적 | 한국교총 설문(교사 1,033명, 약 87% "정착 어렵다"), 국회 입법조사처 간담회 | 확인(보도) |
| 2026학년도부터 이수 기준 완화: 학업성취율 기준 제외, 보충지도 5→3시수, 온라인 보충 허용 | 헤럴드경제 2026-01-27, 머니투데이 2025-09-26 | 확인(보도) |
| 수행평가 기본 점수를 많이 주는 '형식적 운영' 문제 | 교총 설문 보도 | 확인(보도) |
| 교원 정원 긴급 추가 확보(2026학년도) | 교육부 브리핑 | 확인 |
- 이야기로 옮기면: 교감이 "우리 학교는 미이수 0명" 실적을 위해 보충지도를 형식적으로 몰아붙임. 다해의 한 수는 '보충지도의 원래 목적(아이가 실제로 배우게)'으로 판을 뒤집기.
- 걸리는 점: 2026학년도에 기준이 바뀌어서, 극 중 학년도와 기준(성취율 제외·3시수)을 맞춰야 함.

- 시리즈 결(교감이 교사 한 사람에게 떠넘김 → 다해가 규정으로 되돌림)에는 **둘 다** 맞음.
- 일정(11/25 수, 9일 뒤)만 보면 **최성보**가 조금 더 빠름: 장소가 교실·교무실이라 기존 요소로 찍을 수 있고, 새 인물(학생)이 꼭 필요하지 않음. 학맞통은 위기 학생·외부 기관이 나와 새 인물과 장소가 늘어남.
