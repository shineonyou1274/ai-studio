# 교사X 4화~ 작가 방향 검토 v1 (2026-11-16, 편집장)

입력: 사장님 11/16 "백퍼센트 맞는건 아니긴한데 대충 이런 느낌으로" — 「학교도 안 오는 애 때문에 시험이 쉬워지는 이유」(안 오는 학생 + 서류 지옥 + 교감의 신입생 모집 압박, 2분 30초 콘티).
**이야기는 작가가 정합니다.** 편집장은 사실과 시리즈 규칙에 걸리는 곳만 봅니다.

## 1. 사실 확인
| 콘티 내용 | 판정 | 근거 / 고칠 점 |
|---|---|---|
| 미이수 학생에게 방학 중 보충(최성보) | ✅ | 보충지도가 방과후·방학으로 몰림(교총 설문 보도) |
| "수업에 한 번도 안 나온 학생이 기본 점수 + 물시험으로 이수(40%) 통과" | ❌ **고쳐야 함** | 이수에는 **출석률(수업 횟수의 3분의 2 이상)**이 따로 필요. 한 번도 안 나오면 시험 점수와 상관없이 미이수. → "출석은 겨우 3분의 2를 채웠지만 수업에선 엎드려 있던 학생" 또는 "출석 미달은 온라인 보충 3분의 2로 메움"으로 바꾸면 맞음 |
| 학업성취율 40% 기준 | ⚠️ | 2026학년도부터 **선택과목은 학업성취율을 빼고 출석률만** 봄(헤럴드경제 2026-01-27). 공통과목은 성취율 기준이 남은 것으로 보이나 **최종 확정은 원문 확인 필요**. → 극의 과목을 **공통과목(예: 공통국어·공통수학)**으로 두면 "40%"를 쓸 수 있음 |
| 온라인으로 학점 보충, 3분의 2 이상 참여 시 이수 | ✅(보도) | 개선안에 포함(3월 공통과목부터, 9월 선택과목 확대) |
| "미이수자 많으면 소문나서 신입생 모집 어려워져요" | ⚠️ 극 중 인물의 말로는 가능 | 미이수율이 공시·평가에 쓰이는지 **확인 못 함**. 교감의 걱정(대사)으로만 쓰고, 나레이션·자막으로 사실처럼 말하지 않기 |
| 교감이 "시험 쉽게 내라"고 압박 | ⚠️ | 난이도 조정 자체는 위법이라 단정 못 함. 다만 출제·채점은 교사의 평가권, 학업성적관리규정·성적관리위원회 절차가 있음 → 다해의 반격 근거 후보(원문 확인 후 대사로) |
| 수행평가 "이름만 써도 점수" | ⚠️ | 미응시자 기본점수는 학교 학업성적관리규정에 따라 실제로 있음. "퍼준다"는 표현은 규정 범위 안이면 과장 |
| 출석 독려 통화 기록부·불참 사유서 등 서류 | ⚠️ 그럴듯함 | 서식 이름은 학교마다 다름 → 화면 글자는 일반 이름으로("보충지도 계획서", "출석 독려 기록") |

## 2. 시리즈 규칙과 부딪치는 곳
1. **길이 2분 30초 → 회당 75초 이내(매뉴얼 8-1).** 사장님 말씀대로 **2회로 나누면 딱 맞음.**
   - 4화(75초): 안 오는 학생 + 서류 더미 + 교감의 "시험 쉽게" 압박 → **끝: 흔들리는 교사(정우?)** 클리프행어
   - 5화(75초): 평가가 무너지는 장면 → **다해의 한 수**로 뒤집기
2. **나레이션 중심 → 시리즈는 대사 드라마.** 나레이션 문장은 화면 글자(한 줄 팝업)나 인물 대사로 옮기는 것을 제안.
3. **결말이 교사의 패배(쉽게 고침)로 끝남** → 시리즈는 '다해가 규정으로 되돌림'. 4화에서 정우가 흔들리고 5화에서 다해가 받아치면 둘 다 살릴 수 있음.
4. **학생을 조롱·도구로 쓰지 않기.** "코빼기도 안 보이는" 같은 말은 빼고, 학교에 못 나오는 사정이 있을 수 있다는 여지를 한 컷 남기기(바이블 금기: 아이를 도구로 쓰지 않음).
5. **교감 = 난처하고 다급한 사람**(콘티 제안)은 바이블과 잘 맞음: 바이블의 교감은 **재단 실적 압박**(변두리 전보·강등 위기)을 받음 → "신입생 모집"이 그 압박과 바로 이어짐.

## 3. 작가가 정할 것
1. 2회로 나눌지, 나눈다면 4화 끝을 어디서 끊을지
2. 흔들리는 교사를 누구로(정우 / 새 인물)
3. 학생이 안 나오는 사정을 보여 줄지(한 컷), 아니면 화면에 학생을 안 보일지
4. 과목: 공통과목(성취율 40% 사용 가능)으로 할지
