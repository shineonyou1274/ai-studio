## 2. 시청자 모의 판정 (처음 보는 사람)

- **0~3초:** 교감 손 + 폰 + 굵은 남자 목소리 "하은이 어머니가 방금 나한테 전화하셨어요." 하은이가 누군지 모르는 사람에겐 약하지만, 폰 화면 "해외로밍 / 통화 3:12"와 Label "담임과 학생, 몸이 바뀌었다"가 받쳐 준다. **넘길 확률 중간.** 다만 0~3초에 Label·Scene·폰 화면·Tag·Dlg 다섯 덩이가 한꺼번에 뜬다(4화 P2-4 "같은 정보 세 번" 되풀이 위험).
- **완주:** 교실 장면(아저씨 한숨 → 친구들 "미친 거야?" → 책상 쾅쾅)은 웃음 지점이 분명해 25초 이탈을 막는다. 위험 구간은 **K8~K10(교감 손 → 담임 몸 → 엑스트라)**: 얼굴 없는 컷 두 개에 남자 목소리 두 명이 연달아 화면 밖에서 말한다.
- **사이다:** "왜 협박을 해요? 이거 갑질이잖아요!" + 의자 드르륵 + 교무실 정적은 시원하다. 다만 통쾌함이 **약 1.5초** 만에 교감에게 넘어간다(끝 대사가 "넘어가려는 건가요?"로 바뀌면서 교감이 다시 공격하는 모양이 됨). 레드팀 1 참고.
- **다음 화:** "또 그런 걸로 넘어가려는 건가요?" + "헐… 설마."는 6화를 부른다. "교감이 눈치챈 걸까, 비꼬는 걸까"가 남는다. **다음 화 찾을 확률 중상.** 단 지금 대본은 마지막 그림에 지우(담임 몸)의 반응 얼굴이 없다(앞쪽 흐린 옆얼굴 가장자리뿐) — 4화 블라인드 P1-3 "주인공 반응 컷 없음"과 4화 사장님 "헉 하는 느낌이 아니네"가 되풀이된다.
- **화자 구분(대사표만 들었을 때):**
  - 교실: 여고생 목소리가 "지우 녀석"이라고 말하는 순간 "속은 지우가 아니다"가 내용으로 읽힌다. K2 뒷모습의 중년 남자 속마음 "난 이제 죽었다…" → 3초 뒤 같은 영혼이 여고생 목소리로 "아이씨…"가 되는 전환은 Tag(속마음/말함)와 자막 스타일(Mono/Dlg)로만 갈린다. 규칙대로이며 받아들일 만하다.
  - 교무실: **남자 목소리가 둘(교감 Arthur, 담임 몸 sc_teacher_body)** 이다. 얼굴이 보일 때는 문제없지만 K8(교감 화면 밖)→K10(지우 화면 밖)이 이어지면 소리만으로는 누가 말하는지 갈리지 않는다. 두 목소리 음높이·음색 대조 청취가 필요하다(P1-8).
  - Tag의 "겉말"은 제작팀 말이다. 시청자는 모른다(P2).

### P2 — 다듬기

1. **Tag의 "겉말"은 제작팀 말이다.** 시청자는 "겉말"을 모른다. 말하는 줄은 "담임 영혼"(지우 몸이 말할 때)·"지우 영혼"(담임 몸이 말할 때)만, 속마음 줄은 "○○ 영혼 · 속마음"으로. 자막 스타일(Dlg 흰색 / Mono 옅은 흰색)이 이미 둘을 가른다. 4화에서 통일한 표기 틀("○○ 영혼 · 속마음")을 유지하는 쪽. (기획팀)
2. **"그 번호, 선생님들 다 알아!" → "그런 번호, 선생님들 다 알아!"** "그 번호"는 특정 번호 하나로 들리고, "그런 번호"는 수법 전체가 알려졌다는 뜻이 되어 사장님 의도(폭로·예방)에 더 맞다. 음절도 같다. (기획팀)
3. **친구 두 명이 지우와 똑같이 생길 위험.** 같은 교복 + 지우 참조 이미지(C2·C3)라 Seedance가 셋을 비슷하게 만든다. 친구 머리 모양을 따로 지정(한 명 높은 포니테일, 한 명 짧은 단발). 고친 프롬프트에 반영. (생성팀)
4. **Tag 연두(친구)는 키트에 없는 색**이다. 사장님 승인 받거나 교감처럼 흰색으로. (기획팀·편집장)
5. **A4(K11) 팔짱·턱 들기**는 담임 몸 속 지우(여고생 몸짓)로 약하다. 허리에 두 손 올리기 + 턱 들기가 여고생 "따지기" 몸짓으로 더 읽힌다. 사이다 정점 그림이라 기획팀 판단에 맡김. (기획팀)
6. **끝 대사 "또"의 뜻.** "또 그런 걸로 넘어가려는"의 "또"는 처음 보는 사람에게 "전에도 그랬나?"로 들린다. 4화에서 담임 몸이 이상했던 일을 교감이 기억한다는 6화 씨앗으로 쓰면 좋다(기획팀 6화 메모). 녹음 감정 태그는 `[half-joking] [dry]`를 유지하고 `[slightly mocking]`이 세면 교감이 악역으로만 남는다. (기획팀)
7. **"하은이가 어느 집 딸인지, 그렇게 말했건만"**은 화면에 나온 적 없는 경고다(4화 v12에서 교감·기간제 장면을 5화로 넘김). 이해에는 문제없지만 "전에 경고했다"는 사실을 6화에서 쓸 거면 메모. (기획팀)
8. **"생결"은 1화 설정어**라 처음 보는 사람은 모른다. "현체"는 폰 카드로 풀었는데 "생결"은 풀지 않는다. 대사 흐름상 몰라도 되므로 그대로 두되 설명란에 1화 링크. (기획팀)
9. **6초 생성(A3·A5a) 가능 여부·단가** [확인 필요]. 안 되면 5초 생성 후 1.15배 + 컷 길이를 실측에 맞춰 줄인다. (생성팀)
10. **Dreamina 일 무료 한도 120 = 클립 1개/일.** P0·C2·K12b 3개면 3일. 11/1 공개면 컷 생성 D-3(10/29)까지 맞추려면 10/27부터 하루 1개씩 시작해야 한다. (편집장)
11. **폰 화면 코드 합성 3장**은 생성 영상 속 폰이 움직이면 따라가야 한다(추적). A1 폰은 "기울어 카메라 쪽"이라 합성이 쉬운 편, P1 친구 폰은 "흔들기"라 어렵다 → 흔드는 폭을 작게(`waggles … slightly`). (생성팀)

## 7. 레드팀 반론 (빈손 금지)

1. **4화와 같은 끝 모양이다(자기복제).** 4화 끝 = 교감이 담임 몸에게 "김 선생, 뭘 보낸 거예요?"라고 묻고 끊김. 5화 끝 = 교감이 담임 몸에게 "김 선생, … 넘어가려는 건가요?"라고 묻고 끊김. 두 화 연속 "교감 질문으로 끊기"다. 구독자는 6화도 같은 끝을 예상한다. K12b로 마지막 그림을 지우 반응("헉" + 입 막기)으로 바꾸면 적어도 끝 그림은 달라진다. 6화는 교감이 아닌 다른 끝을 미리 정해 둘 것.
2. **사이다가 1.5초짜리다.** 사장님 수정으로 끝 대사가 "또 그건가요?"(던지는 농담)에서 "또 그런 걸로 넘어가려는 건가요?"(되받아치는 공격)로 바뀌어, 마지막 박자의 승자가 교감이 됐다. "이거 갑질이잖아요!" 뒤 교감이 실제로 당황하는 그림은 입 열었다 닫는 1초뿐이다. 시청자는 "시원했다"보다 "또 졌네"로 나갈 수 있다. 사장님 결정이라 대사는 그대로 두되, **교감이 말문 막히는 그림(K12a 행동 1)을 최소 1초는 지키고 정적을 0.8초 아래로 줄이지 말 것.** 길이를 줄일 때 이 정적부터 깎는 일이 없어야 한다.
3. **두 장소가 서로 영향을 주지 않는다.** 교실 21초와 교무실 30초는 "같은 시각"이라는 Scene 말고는 이어지는 사건이 없다(담임은 교무실 일을 모르고, 지우는 교실 일을 모른다). 거울 구조("지우 녀석" / "우리 쌤")는 기획 문서에서는 선명하지만 화면에서는 25초 떨어져 있어 시청자가 연결할 가능성이 낮다. 길이가 65초를 넘으면 가운데 교실 장면이 "곁가지"로 느껴질 위험이 커진다. 블라인드 검수 문항에 "교실 장면과 교무실 장면이 왜 같이 나왔는지 설명할 수 있는가"를 넣을 것.
4. **원인 제공자가 큰소리치는 구도.** 이 사건의 시작은 지우의 비꼬는 문자(4화)다. 5화만 보면 교감이 일방적 악역이고, 4화를 본 교사 시청자는 "잘못한 사람이 갑질이라며 큰소리"로 볼 수 있다. 댓글이 '교감 편/지우 편'으로 갈리면 참여에는 좋지만, 교사 채널 이미지에는 부담이다. 6화 사과 장면은 선택이 아니라 필수로 잡을 것.
5. **"음성 예상 길이" 실수가 두 화 연속이다.** 4화에서 예상 1.8초가 실측 4.2초였는데도, 5화 대본은 같은 방식(초당 7~9음절)으로 다시 잡았다. 이번에는 끝 대사 수정까지 같은 방식(36음절 3.9초)으로 계산됐다. 기획팀 규칙에 "녹음 예상 길이 = 음절 ÷ 4.5" 같은 고정 공식이나 "음성 먼저 녹음"을 넣지 않으면 6화에서도 되풀이된다.
