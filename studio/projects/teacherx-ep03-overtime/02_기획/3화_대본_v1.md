# 교사X 3화 「야근 강요」 대본 v1 (2026-11-16, 편집장 초안 — 작가가 고침)

사장님 11/16: "A+C로 가자, 올해 새로 온 선생님으로". A = 다해가 '초과근무 신청서의 사유 칸'으로 판을 뒤집음, C = 교감의 대물림을 '살짝'.
**대사는 모두 초안이에요.** 마음대로 고치거나 다시 써 주세요. 편집장은 고친 대본의 법·사실만 다시 봅니다.

## 훅 (결말 먼저, 3~4초)
- 밤 9시, 불 꺼진 교무실. 교감이 혼자 열쇠 꾸러미로 문을 잠근다.
- 소리: 12번 다해 대사의 끝부분("…교감 선생님 이름으로요."). 대사 자막은 없음.
- 훅 제목(안): **"야근시키려면 사유부터 쓰시죠!"** — 다른 안: "'신규는 9시까지 남아' 교감, 결재 칸에서 막혔다"
