## 엄격한 블라인드 확인(받아쓰기 + 프레임만, 새 시선)
1. 교감이 담임 몸(안은 지우)을 노려보자 지우가 속으로 "뭐라고 하지?" 고민하다가 "오늘 완전 교장 포스세요!"라고 아부하고, 교감은 "허허… 이 사람…" 하며 책상을 톡 친다.
2. 옆 반 최 선생님이 울고 있고, 옆자리 선생님이 누가 최 선생님 텀블러에 침을 뱉고 욕 쪽지를 남겼다고 속삭인다.
3. 회상: 작년에 학생들이 "요새 텀블러 안 들고 다니세요?"라며 최 선생님을 놀렸다.
4. 옆자리 선생님이 "작년에 선생님 반이었던…" 아이라고 넘겨짚자, 담임 몸에서 여고생 목소리로 "헐—"이 새고, 지우는 "아니… 헐레벌떡… 놀랐습니다"로 얼버무리고 아는 척한 뒤, 진짜 담임(지우 몸)에게 DM으로 묻는다.
5. 교실의 지우 몸(담임)은 노안 놀림을 받고, 창밖 벤치에 혼자 앉은 작년 자기 반 아이를 보며 걱정하다가 "할아버지 같다"는 놀림에 "에헴, 경치가 좋구나"로 넘긴다.
- 의도한 흐름과 비교: 전부 이어짐. 남은 고리 약점:
  - P1 — 첫머리 교감은 이름 없이 "교감 선생님"이라는 아부 대사로만 정체가 드러남(첫 2.8초 동안은 누군지 모름; 지난 화 한 줄이 "교감이…"라 도움).
  - P2 — 교감 손 컷은 손이 실제로 내려치지 않아(정지한 손 + 흔들림·효과음) '톡'이 약함.
  - P2 — 분할 화면 아래 주먹이 크게 흐림(원본 초점이 벤치 쪽), 지우 몸이라는 것은 PIP(담임 영혼)와 자막으로만 알 수 있음.
  - P2 — 회상 학생과 벤치 아이가 다른 사람이라는 것은 "학생들"로 흐려졌지만 완전히 분리되진 않음.
- 받아쓰기 흔들림(녹음 발음): 족지엔, 지효야, 펌글씨, 반해래요, "작년에"→장면에, "놀랐습니다"→몰랐습니다(속도 1.05배 구간). 자막은 대본대로.
