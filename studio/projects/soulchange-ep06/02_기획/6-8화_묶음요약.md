## 2. 이어지는 고리

- **5화 → 6화:** 교감 "AI 빙의 드라마… 수작인가요?" → 6화 0.2초 "…농담이에요, 농담." → 지우 속마음 "휴… 살았다." → 흐느낌이 끊음. 들킴 줄기는 여기서 닫고 다시 키우지 않는다.
- **6화 → 7화:** 지우는 모르고 담임만 아는 아이 → 7화에서 두 사람이 정보를 합침(담임의 기억 + 지우의 아이들 말 읽기). 6화 끝 교실 컷(H3)의 2초를 7화 K4a로 재사용해 같은 시각으로 이어 붙인다. 6화 회상에서 비웃던 아이(S1 목소리)가 7화에서 "저희가 뭘 하면 돼요?"라고 손을 든다.
- **쪽지로 시작해 쪽지로 끝남:** 6화 `티○년` 쪽지 ↔ 7화 `최 쌤, 미안해요` 쪽지. 6화 텀블러 ↔ 7화 새 텀블러.
- **7화 → 8화:** 상담 탁자(같은 공간) / 하은이네 힘(학운위 위원장 → 체육관 감사패 → 이사장 형님)을 한 화 안에서 차례로 드러냄. 4화 지우가 보낸 문자, 5화 "어느 집 딸"·"기간제 연장"을 회수.
- **8화 → 9화(제안):** 이사회와 재계약 위기. 들킴 카드·행특 초안·쌤 없는 단톡방은 계속 아껴 둠.
