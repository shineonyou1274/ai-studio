# 사장님 원안 (2026-11-13) — 《신규가 너무 일을 잘함》(가제)

사장님 지시: "아니야 180초 이내(3분)로 수정 부탁 / 정우, 다해, 교감 구도로 봐줘"
원안 인물: 강하늘(신규, 해맑은 일잘러) · 이선생(5년 차, 착해서 가스라이팅당하는 선배) · 박교감(여우형 관리자)
원안 씬: ① 교무실 3시 — 반려 팝업, 박교감이 이선생 몰아붙임("내가 언제 그렇게 하랬어? 책임감이 없어") ② 타깃 전환 — 기획서를 신규에게 떠넘김("품앗이가 우리 학교 전통"), 신규는 웃으며 수락, "30분이면 끝냅니다" ③ 40분 뒤 교감실 — 1~6차 반려 사유를 편람·지침과 대조, 장학사 유권해석, "교감 성함은 끝까지 안 밝혔다" ④ 쐐기 — 초과근무 42시간과 반려 시각 일치, 갑질 조항, "지금 승인 누르시면 명예가 지켜집니다" → 승인 광클 ⑤ 에필로그 — 최종 승인, 4시 반 칼퇴, 치킨, 넋 나간 교감
(원문 전체는 대화에 붙여 주신 것 — 같은 글이 여러 번 붙어 있었음)
