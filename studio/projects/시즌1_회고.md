## 2. 주의할 점 (실제로 사고가 났던 곳)

### 크레딧
- 12화 견적 약 270 → 실제 333, 8화 240. 다시 찍기와 목소리 후보가 견적에 없었다.
- **다음엔:** 견적에 다시 찍기 몫 30%를 넣고, 다시 찍기는 한 화에 한 번까지만 한다. 넘으면 먼저 묻는다.

### 이야기·인물
- **지우 얼굴이 화마다 달라 보임, 버릇없어 보임(12화).** "지우 몸 안의 김병만" 연기(다리 벌림, 씩 웃음)가 지우 본인처럼 보였다. 바뀐 몸의 연기는 해설 자막과 함께, 얼굴은 짧게.
- **두 몸이 한 화면에 나란히 있으면 어색함.** 상담실에 담임 몸과 지우 몸을 같이 앉힌 컷은 결국 다 잘랐다. 처음부터 따로 찍는다.
- **사장님 원문 대사는 뉘앙스까지 확인.** "…지우…니?"(몸이 바뀐 딸에게 '니?'는 이상함), "죄…", "생결 다시 쓸게요" 모두 나중에 뺐다. 대본 단계에서 읽어 보고 한 번 묻는다.
- **유튜브 분석:** 첫 1~2초에 넘기느냐로 갈렸다(2화 65.7%, 3화 22.9%). 제목에 '몸이 바뀌었다'가 있을 때만 검색이 들어왔다. '여고생'·'향기'는 엉뚱한 시청자를 불렀을 수 있다. → 첫 화면, 제목, 띠는 기획 단계에서 정한다.
- **길이:** 70초 규칙인데 8·9화 1분 40초, 12화 2분 18초. 마지막 화가 아니면 70초를 지킨다.

### 목소리
- 몸 목소리에 "teenage girl" 태그를 넣어 담임 몸이 여고생 목소리가 됐다(11화 v2·v4). 속마음과 겉말 규칙이 헷갈려 11화를 여섯 번 고쳤다.
- **다음엔:** 녹음 전에 줄마다 '누구 몸 / 누구 앞 / 속마음인가' 표를 먼저 만든다.
- 계정 목소리는 3개가 한도라 새 인물은 기본 목소리나 seed_audio 참조 음성으로 한다.

### 편집 기술 (코드 실수)
| 사고 | 원인 | 다음엔 |
|---|---|---|
| 자막이 대사보다 0.3~0.9초 어긋남 | 긴 대사를 길이 비율로 나눔 | 처음부터 받아쓰기 단어 시각으로 나눔 |
| "교감샘도 저처럼 살아 봐라" 입이 2.5초 어긋남 | 컷 안에서 입이 움직이는 구간을 확인 안 함 | 립싱크 컷마다 입 구간을 프레임으로 확인 |
| "에헴"처럼 들린 이상한 소리 | 배경음 파일을 두 번 넣음 | 빌드 스크립트를 공통 모듈로(복사·붙여넣기 금지) |
| 오른쪽 위 아이콘이 0.2초 늦게 바뀜 | 컷 길이 반올림 오차 누적 | 시각은 실제 프레임 수로 계산 |
| 1화 "다음 편" 화면, 1화 노트북 글자가 끼어듦 | 재사용 원본의 구간을 끝까지 안 봄 | 재사용 구간은 0.2초 간격 프레임 시트로 확인 |
| 고양이 입이 움직이는데 대사 없음 | 원본 고양이는 줄곧 말하는 중 | 입 다문 구간만 쓰기 |
| 코드로 만든 "야옹"이 사람 소리처럼 들림 | 합성음 한계 | 동물·사물 소리는 CC0 음원 |

### AI 영상의 흔한 사고 (프레임으로 찾아 자르기)
- 배경 학생에게 주인공 얼굴이 복제됨(김병만 닮은 학생)
- 다리가 책상을 통과함
- 같은 장면인데 바닥, 소파, 창문이 컷마다 바뀜
- 엑스트라가 복제됨
- 표지판 글자가 깨짐
- 바지 무늬가 일렁임
- 다른 인물에게 이름표가 붙음

## 3. 하지 않을 것
- 견적 없이 생성하거나, 다시 찍기를 반복하지 않는다.
- 직접 듣지 못한 소리를 "확인했다"고 말하지 않는다. 받아쓰기·음높이로 본 것과 사장님 청취가 필요한 것을 나눠 말한다.
- 외부 검수(Gemini)를 그대로 믿지 않는다. 12화 v7의 "'이건 좀 남았네' 장면이 남아 있다"는 지적은 틀렸다. 반드시 프레임으로 확인한 뒤 반영한다.
- 프롬프트에 정지 유발어(freeze, still 등)나 나이·성별 목소리 태그를 넣지 않는다. 'skirt'처럼 필터에 걸리는 말도 쓰지 않는다.
- 어머니 얼굴, "그 학생", "신고" 같은 시리즈 금지 사항을 어기지 않는다(프롬프트에 미리 적는다).
- 덮어쓰기, 키트 수정, 저작권 음원을 쓰지 않는다.
- 무거운 렌더링을 동시에 두 개 이상 돌리지 않는다(8화 메모리 부족으로 멈춤). `pkill -f`로 자기 셸까지 끄지 않는다.
- 한 대화에 여러 작품을 섞지 않는다(사장님 판단으로 새 채팅 분리).

## 4. 다시 한다면 — 순서

1. **시즌 기획(한 번에)**
   - 타깃(교사)을 정한다.
   - 제목·첫 2초·띠·커버 문구 규칙을 정한다. '몸이 바뀌었다'를 넣고 오해 부를 말은 뺀다.
   - 시즌 줄거리 전체와 회차별 70초 상한을 정한다.
   - 인물·장소·소품 요소를 한 번에 등록한다.
   - 목소리 3칸 배분을 정한다.
2. **회차 대본**
   - 사장님 원문 대사를 뉘앙스까지 확인한다.
   - 대사마다 '누구 몸/누구 앞/속마음' 표를 만든다.
   - 같은 장면에 두 몸을 나란히 두지 않는다.
3. **녹음**
   - 2테이크를 뽑는다.
   - 받아쓰기와 음높이 표로 고른다.
   - 단어 시각을 저장한다(자막에 쓴다).
4. **촬영**
   - 견적(다시 찍기 30% 포함)을 받고 승인받는다.
   - 립싱크 컷은 녹음을 참조로 넣는다.
   - 듣는 얼굴, 손, 인서트 컷을 넉넉히 같이 찍는다(교차 편집용).
5. **편집**
   - 공통 빌드 모듈을 쓴다(프레임 기준 시각, 단어 시각 자막, 배경음 한 번만).
   - 재사용 구간은 프레임 시트로 확인한다.
6. **자체 검수**
   - 1초 간격 프레임 시트를 본다.
   - 컷 경계 ±0.3초를 본다.
   - 자막과 받아쓰기를 대조한다.
   - 립싱크 구간을 확인한다.
   - 첫 2초를 본다.
7. **외부 검수**
   - Gemini 한 번과 사장님 한 번으로 묶는다.
   - 지적은 프레임으로 확인한 뒤 고친다.
   - 고친 목록과 그대로 둔 것(이유)을 함께 보고한다.
