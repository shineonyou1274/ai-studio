# 교사X 11화 방향 3안 v1 (2026-11-25) — 공개 12/11(금) 18:00
이어받는 것: 10화 끝 이사장 "…조만간, 한번 들르겠습니다." / 시즌 흐름 v3: 11화 = 기자가 옴 → 뉴스, 이사장은 정정 공문을 꺼내려다 못 꺼냄 / 복선(만년필 뚜껑 만지작 1초, 해외 번호 부재중 1번) / 교감 음모 계속 / 체험학습은 아껴 둔 소재
원칙: 마음의 상상(매뉴얼 0절 11), 화면으로 인과, 사이다 우선, 다해 무표정·존댓말

## 안 1 (추천) — "수업 중엔, 이사장님도 기다리십니다"
- 이사장이 정정 공문(봉투)을 들고 학교에 옴. 그런데 이 학교 규칙: **수업 중엔 공문·메신저·전화·호출 없음**(10화에서 아낀 규칙을 화면으로).
- 교무실 아무도 다해를 부르지 않음 → 이사장이 복도에서 수업이 끝나길 기다리며 교실 창으로 수업을 봄(정우의 AI 오류 찾기 수업, 학생 손만).
- 같은 시각, 9화 민원 기사 쓰러 온 기자 → 민원 1차 응대는 **교감**(10화 규칙)이 함. 교감이 쩔쩔매며 응대하다 기자를 교실 앞으로 안내 → 기자도 수업을 봄.
- 종이 울림 → 다해가 나와 이사장에게 "수업 중이었습니다. 무슨 일이십니까?" → 이사장은 봉투를 등 뒤로 숨김.
- ⑦ 저녁 뉴스(극 중) '공문 없는 교실' 보도 → 이사장 책상 서랍에 봉투가 들어감 / 다해 만년필 뚜껑 만지작 1초.
- 사이다: 이사장조차 수업을 방해 못 함 + 교감이 처음으로 민원을 직접 받음. 9화 민원과 이어짐.

## 안 2 — "책임자: 교장 독고다해" (체험학습)
- 아껴 둔 체험학습 소재를 지금 씀. 교사들이 사고 책임 때문에 체험학습을 포기하려 함 → 다해가 인솔 계획서 책임자 칸에 자기 이름, 전문업체·보험, 직접 버스에 오름.
- 기자는 '사고 나면 교사 처벌' 기사를 쓰러 왔다가 교장이 직접 인솔하는 장면을 봄.
- 장점: 사이다 가장 큼. 단점: 장소(버스·체험지)가 새로 많아 생성 비용 큼(약 350↑), 이사장 방문과 엮기 어려움 → 12화(해외 시찰단)와 묶는 게 나을 수도.

## 안 3 — "민원은 교감 선생님께"
- 교감이 민원대응 1차 창구가 된 첫날. 전화·방문이 몰려 교감이 하루 종일 응대(코믹), 교사들은 처음으로 수업만 함.
- 민원인 중 하나가 사실 기자(9화 민원 취재) → 교감의 응대 녹음이 기사에.
- 장점: 교감 코믹 극대화. 단점: 다해 사이다가 약하고 교감이 조롱처럼 보일 위험(시리즈 뜻: 누구도 악당 아님).

## 편집장 추천: 안 1
10화 끝 "들르겠습니다"를 바로 받아 이사장 방문이 자연스럽고, 아껴 둔 '수업 중 연락 없음'·'민원 1차 응대는 교감'을 장면으로 보여 줌. 체험학습은 12화(시찰단이 보는 학교)에서 크게.
