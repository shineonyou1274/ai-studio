# 교사X 11화 방향 v2 — 훈육 + 국어 사이다 (2026-11-27) · 공개 12/11(금) 18:00
사장님 소재(11/27): 교사는 임용시험을 통과한 전문가 → 그에 맞는 대우 / 학생 '질문'의 수준 / 화장실 간다며 10분 지각, "친구가 늦어도 된대요" / 화내지 않는 정당한 훈육 / "우리 엄마도 저 안 혼내는데" / 신입생 부모 "화장실 청소 제가 대신 하면 안 되나요" / 대회 우승 후 SNS 자랑(대표성 교육) / 다해의 국어 말발 사이다 부활.
뼈대: 3안 중 **안 1**("수업 중엔, 이사장님도 기다리십니다")에 이 소재를 얹음. 이사장과 기자가 창밖에서 보는 수업이 바로 '다해의 훈육'.

## 장면 흐름 (약 100초)
0. 훅(결말 먼저): 멍한 학생 뒷모습 + 창밖의 이사장·기자 / 큰 제목만 "선생님이 뭔데요?"
1. 이사장 도착, 손에 정정 공문 봉투. 교무실: "수업 중입니다"(호출 없음). 이사장이 복도 창가에서 기다림.
2. 같은 시각 기자 방문 → 민원 1차 응대는 교감. 교감 책상 전화: 신입생 어머니 "화장실 청소, 제가 대신 하면 안 될까요?" 교감 쩔쩔.
3. 교실. 손 드는 학생들: "화장실 가도 돼요?" "숙제 있어요?" "아까 그거 다시요."
   다해: "그건 허락이고, 그건 확인이고, 그건 복습이야. 그런 건 짝한테. 나한텐 막힌 생각을 가져와." 칠판 두 칸 [친구에게 | 선생님에게]. (양념, 뜻풀이 아님)
4. 10분 늦게 들어온 학생: "친구가 늦어도 된대서요." → 다해: "5분이랬지. 그 5분이 약속이야." → 학생: "선생님이 뭔데요. 우리 엄마도 저 안 혼내는데."
   **결정타(국어)**: "선생. 먼저 선(先), 날 생(生). 너보다 먼저 살아 본 사람이야."
   (한 박자) "그리고 나도 보니까 너희 어머님 훌륭하시더라. 그래서 자식을 잘 키우셨을 것 같아. 밖에서 이러는데 뭐라고 안 하셨을 리가 없지. 그러니까 부모님 욕보이지 말고, 잘하자." → 학생 멍, 말 못 함(화 안 냄).
   창밖 이사장, 봉투를 쥔 손에 힘이 빠짐. 기자 수첩.
5. 종. 다해 복도로 → 이사장에게 "수업 중이었습니다. 무슨 일이십니까?" → 봉투 등 뒤로.
   교감이 청소 민원 전함 → 다해: "어머님께 전해 주십시오. 대신 해 주시면, 깨끗해지는 건 화장실뿐이라고요."
6. 저녁 뉴스(극 중) '화내지 않는 교실' → 이사장 서랍에 봉투 / 다해 만년필 뚜껑 1초 → 마지막 프레임 다해 얼굴.
* 교사 대우 한 줄(선택, 교무실 또는 교감에게): "선생님들, 임용시험 통과한 전문가입니다. 화장실 허락하라고 뽑은 분들 아닙니다."

## 대회 자랑(SNS) 소재 → 12화로
12화 해외 시찰단 앞에서 학교 대표로 인사할 학생(전국대회 우승 선수)이 "수행평가 면제ㅋㅋ" 자랑 글을 올림. 나쁜 뜻 없음, 그냥 신남. 다해의 결정타 후보: "대표. 대신할 대(代), 겉 표(表). 오늘부터 네 얼굴이 이 학교의 겉이야." 망신 주지 않고 가르침.
- 실제 선수·팀 이름은 쓰지 않음(매뉴얼: 누구도 조롱하지 않음). 사장님이 본 "학교 안 아이들이랑 똑같다"는 시선을 학교 안 학생으로 그대로 옮김.

## 고증 메모
- 공립 교사 임용시험: 시·도교육청 주관(1차 출제 한국교육과정평가원). 대사에서는 '국가고시' 대신 '임용시험'.
- 병역 특례: 아시안'컵'이 아니라 아시안'게임' 금메달(예술·체육요원). 이번 극에는 쓰지 않으므로 사건 세부는 확인하지 않음.
- 학생 청소: 우리나라 학교에서 학생이 교실·화장실 청소를 하는 것은 흔한 교육 활동.
