# 10화 대본 v2 안 (편집장, 2026-10-31) — 사장님 v2 영상 지적 반영, 생성 전 생각만

사장님 지적(원문): "너무 향수가 노골적이다. 엄마의 학대가 메인이어야 하는데 너무 작위적인 느낌. 지우가 어깨치는 것도 어색하고. 하은이 귀국 장면도 어색 갑툭튀. 하은이는 '그 시간 학급 단톡방'이란 장면 전환 텍스트 잠시 보여 줌 좋겠어. 첨에 현석이네도. 엄마랑 현석이 대화 때 하얀 덩어리는 뭐지. 굳이 향수병을 통째로 들고 다니는 이들 없잖아."

- 하얀 덩어리 = K2 위쪽에 걸린 거실 펜던트 조명(흰 원판). 확대로 뺀다.
- 원인: 큰줄기 문서의 "무향 섬유유연제·같은 향수 동지" 웃음을 그대로 그림으로 옮겨 향수병이 세 컷(K1·K3·K11)에 나왔다. 향수는 8·9화에서 이미 '단서'로 다 썼으니 10화에서는 물건으로 안 보인다.

## 바꾸는 줄기
1. 중심 = 엄마의 학대(보여 주되 직접 때리는 장면 없이): 큰 목소리 회상 + 손목을 세게 잡는 손(금반지) + 소매 아래 옅은 멍 1초. 한여름 긴팔(8화 떡밥)이 여기서 풀림.
2. 향수병 = 화면에서 뺌. "엄마 냄새가 나면 숨이 막혔는데" → **"엄마 목소리만 들려도 숨이 막혔는데"**로 다시 녹음(0.3크레딧).
3. 어깨 개그(K7)·향수 동지(K11) 뺌. 웃음은 끝(단톡·DM·"헐")에만 — 이 화는 무게 편.
4. 장면 전환 글자 카드(검은 화면 0.8초): **"그날 밤, 현석이네"**, **"그 시각, 학급 단톡방"**.
5. 하은은 '귀국'이 아니라 단톡 속 이름으로만: 미인정결석 이야기 → 그걸 본 김병만 영혼이 지우의 1화 생결이 떠올라 DM. (하은 얘기 → 지우 비밀로 이어지는 이유가 생김)
