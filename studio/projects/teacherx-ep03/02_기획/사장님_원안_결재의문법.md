# 3화 사장님 원안 (2026-11-13 전달) — 《신규가 너무 일을 잘함》 「결재의 문법(文法)」

원안 인물: 박교감(사자성어를 틀리게 쓰며 연가 사유를 캐묻는 관리자) · 이선생(39도 열에도 조퇴 결재를 못 받는 5년 차) · 강하늘(국어과 신규, 표준어·어문 규범으로 멘붕시키는 해맑은 교사)
→ 2화처럼 **다해·정우·교감** 구도로 옮길 예정(사장님 확인 필요). 다해=국어 교사라 원안의 '국어식 결정타'와 잘 맞음.

## 흐름 (원안 그대로 요약)
교감실 오전 → 교감이 조퇴 사유 '개인 사정'을 트집, "사명감 = 목숨 사(死)에 목숨 명(命)" → 열 39도 이선생 반려 → 강하늘 등장, '사명(使命)'의 사는 '부릴 사' 정정 / '비유'·'훈계'·'교정'의 뜻으로 받아침 → 교감 "병명·병원 육하원칙으로 써 와" → 강하늘: 연가·조퇴 사유 기재 의무 없음, 사생활 추궁은 헌법 17조 침해, 수업 교체·대체 지도·체온 기록 첨부로 '지장' 없음 → 결재(決裁)의 '재(裁)=마름질' 결정타, 직권남용 경고 → "협박이 아니라 충정" → 승인 → 이선생 병원 → 강하늘 자기 연가도 올림, 헛개차 → 교감 "국어과아악!"
