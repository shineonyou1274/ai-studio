# 3화 수능 감독 편 — 제미나이 초안(작가안) 법·사실 검토 v1 (2026-11-15)

사장님(11/15): "나는 작가야. 너는 법에 위배되는지 오류 없는지 봐 줘. 어차피 이 스토린 계약직 경매 입찰로 들어왔다는 말도 안 되는 설정이야. 그러니까 그대로 해 줘."
→ **이야기·대사는 작가안(제미나이 초안 2개) 그대로 둔다.** 편집장은 ① 실제 법에 걸리는지(만드는 우리 쪽), ② 극 안에서 사실·법이 틀린 곳만 본다. 고칠 안은 '최소 수정 제안'이며 사장님이 고른다.
- 판정: ⛔ 바꿔야 함(실제 법·플랫폼 위험) / ⚠️ 사실 오류(교사 시청자가 "틀렸다" 할 곳) / ✅ 문제없음

## 1. 우리(제작) 쪽 위험 — 실제로 걸릴 수 있는 것

## 3. 그대로 가도 되는 것 (작가안)
- 전체 흐름: 짓밟힘(감독관 회의) → 희생양(정우) → 순종하는 척 → 수능 날 감독관실 반격 → 쐐기·의자 들고 칼퇴. **법적으로 문제없음.**
- 교감의 과장된 겁주기, 정우의 하소연, 다해의 매뉴얼 복선.
- 감독관 의자를 마지막 소품으로 쓰는 것(올해 실제 도입이라 시의성 좋음).

2. "대학 하청업체" 대사: **'국가 시험인데 책임은 교사 한 명' 쪽으로** / 그대로(사실과 다름을 감수)
3. 캡처: **다시 쓴 가짜 게시글 + 장비 나열 빼기** / 대사로만
