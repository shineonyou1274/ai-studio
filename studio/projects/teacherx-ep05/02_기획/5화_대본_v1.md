# 교사X 5화 「1등급 0명」 대본 v1 (2026-11-17, 편집장 초안 — 작가가 고침)

사장님 11/17: "5화 대본 초안 써줘. 다만 피식 웃지 않고 그냥 고개 획 돌리면서 쌩까는 거.. 이제 진짜 참교육간다"
바탕: 4화의 끝(정우가 7번 문항을 지우고 쉽게 고침) → 4화 14 다해의 경고("만점자가 열 명 중 한 명을 넘으면, 1등급이 한 명도 안 나올 수 있거든요")가 그대로 터짐. 쉬워진 시험 → **상위권 학부모 민원** → 교감이 정우에게 책임을 넘김 → 다해의 반격. 새 설정(다해 = 이사장 딸, 언니 대신 끌려옴)은 **복선 한 컷**만.
**대사는 모두 초안이에요.** 마음대로 고치거나 다시 써 주세요. 편집장은 고친 대본의 법·사실만 다시 봅니다.

- 새 인물·새 목소리 없음(학부모 목소리는 들리지 않게, 교감 통화로만) → 녹음은 다해·교감·정우 셋.

## 한 줄
쉽게 낸 통합과학 기말에서 만점자가 쏟아져 1등급이 한 명도 안 나온다. 학부모 전화가 빗발치자 교감은 "누가 이렇게 쉽게 내랬어!"라며 정우에게 덮어씌우고, 다해는 교감이 직접 결재한 시험지와 교감 본인의 말로 되돌려 준다. 마지막 전화는 교감이 받는다.

## 훅 (결말 먼저, 3~4초)
- 교무실. 전화벨이 연달아 울리고, 교감이 수화기를 든 채 굳은 얼굴(입은 움직임). 모니터에 '통합과학 1학년 1등급 0명' (글자는 편집).
- 소리: 05번 교감 "누가 이렇게 쉽게 내랬어!" — 대사 자막 없음, 큰 제목만.
- 훅 제목(안): **"쉽게 내라던 교감,\N1등급 0명 나오자…"** / 다른 안: "만점자 28명, 1등급은 0명"

## 법·사실 확인 (편집장)
| 대사·장면 | 확인 | 근거 / 주의 |
|---|---|---|
| 01~02 만점자가 많아 1등급 0명 | **맞음(보도된 실제 일)** | 5등급제 1등급 = 상위 10%. 1등급 0명 학교 보도(뉴시스 2026-07-28). 만점 28명은 극 중 숫자(학년 약 200명 가정 시 10% = 20명). 동점자 등급 계산식(중간석차)은 원문 확인 전이라 **대사로 설명하지 않음** |
| 03 "백 점인데 1등급이 아니라고요?" | 맞음 | 만점자가 10%를 넘으면 만점자도 1등급이 아닐 수 있음. "2등급"이라고 단정하지 않음(계산식 확인 전) |
| 결재판 '출제 원안 검토' → 교감 결재 | ⚠️ **그럴듯함, 원문 확인 필요** | 많은 학교에서 출제 원안은 교과협의회 검토 → 교감·교장 결재를 거침. 시·도교육청 학업성적관리 시행지침과 학교 규정마다 다름 → 화면 글자는 일반 이름만, 설명란에 단정하지 않음 |
| 10~11 결재했으니 책임이 있다 | 극 중 주장 | "위법"이라 하지 않음. 결재선에 이름이 있다는 사실만 보여 줌 |
| 13 학부모 민원 전화를 교감이 받음 | 극 중 전개 | 학부모를 악당으로 그리지 않음(정당한 문의로) |
| 복도 이사장 사진 | 극 중 설정 | 세계관 설정이라 사실 확인 안 함(매뉴얼 2절). 실존 인물·실존 법인 이름 쓰지 않음 |
