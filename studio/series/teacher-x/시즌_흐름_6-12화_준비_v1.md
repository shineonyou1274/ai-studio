# 교사X 시즌 흐름 준비 v1 — 인사 예고 → 교장 다해 → 교감의 시기 (2026-11-17, 편집장 초안)

사장님 11/17: "이제 조만간 다해가 교장 되기 전에 인사발표 예고도 뜨고 그때의 교감 감정선과 행동, 그리고 교장 된 후의 사이다 행정, 이를 시기하고 방해하는 교감을 그려야 해. 그러니 대비하자. 교장이 된 뒤에도 사람들은 이사장 손녀인 걸 몰라야 해. 그래야 괴롭히지."
**이야기는 작가가 정합니다.** 아래는 뼈대 제안과 사실 확인 메모예요. 화마다 7비트(매뉴얼 2-1)를 지킵니다.

## 0. 바뀌는 큰 줄기
- 10화쯤 교장 등장 = **신분 공개가 아님.** 사람들은 여전히 "계약교사 출신이 어떻게 교장이 됐지?"만 안다 → 교감·동료의 의심과 괴롭힘이 계속된다.
- 정체(이사장 손녀) 공개는 **시즌 끝**으로 미룸(제안). 빨간 만년필 두 자루 페이오프도 그때.
- 가족관계증명서: 1부에선 교감이 "내라"고 괴롭히는 도구 → 2부에선 교감이 다해의 뒤를 캐는 열쇠(“교장 임명 서류 좀 봅시다”).

## 1. 교감 감정선 (한 줄씩)
| 시기 | 교감의 속 | 겉으로 하는 행동 |
|---|---|---|
| 6~8화 | "내가 다음 교장" — 재단 실적만 채우면 된다 | 다해 괴롭힘이 세짐(회식 따돌림, 서류 독촉, 잡일), 이사장 앞 아첨 |
| 9화 (인사 예고) | 공문 "차기 교장 공모·이사회 의결 예정" → 자기라고 확신 | 교무실에서 미리 '교장 행세', 축하 화분 미리 받음, 다해에게 "내가 교장 되면 계약부터 정리" |
| 10화 (발표) | 충격 → 굴욕 | 발표문에 '독고다해' — 화분 리본을 몰래 떼는 손(웃음+굴욕 한 컷) |
| 11~ (2부) | 시기 → "뭔가 있다"는 의심 | 결재 지연, 교사들 선동("계약교사 출신 교장 밑에서 어떻게 일해"), 민원 사주, 뒤 캐기 |
| 시즌 끝 | 정체가 드러나는 순간 | 다해 가슴의 빨간 만년필과 이사장의 만년필을 번갈아 보며 얼어붙음 |

## 2. 화별 뼈대 (제안, 작가가 바꿈)
| 화 | 소재 | ⑤반전 / ⑥사이다 | ⑦떡밥 |
|---|---|---|---|
| 6 | 친목회 회식 따돌림(다해만 몰래 메신저, 정우가 알게 됨) | 다해가 회식 대신 정우·학생들과 다른 일을 해냄(작게) | 가족관계증명서 재독촉 |
| 7 | 잡일 몰아주기(업무분장 갑질) | 업무분장표의 결재선으로 되돌림 | 재단 공문 봉투 |
| 8 | 교감이 '교장 될 사람' 행세 시작 | 교감의 실수를 다해가 덮어 줌(빚지게 만듦) | 이사장이 다해 쪽을 한 번 더 봄 |
| 9 | **인사발표 예고**(이사회 의결 예정 공문) | 교감 확신, 축하 화분 | "발표 내일 오전 9시" |
| 10 | **교장 발표** — 다해 | 교감의 화분 리본 / 다해 첫 지시 한 줄(예: "회식, 오늘부터 전원 초대입니다") | "계약교사 출신이 어떻게?" — 교감이 서류를 뒤지기 시작 |
| 11~ | 사이다 행정(1부에서 당한 일을 하나씩 제도로 고침) vs 교감의 방해 | 매화 하나씩 | 교감이 정체에 점점 다가감 |

2부 사이다 행정 후보(1부와 짝): 회식 따돌림 → 친목회 회비·초대 원칙 / 잡일 몰아주기 → 업무분장 공개 / 서류 지옥(4화) → 보충지도 서류 줄이기 / 시험 쉽게(5화) → 출제·검토 절차 바로잡기 / 체험학습 책임(바이블) → 책임 나누기.

## 3. 사실 확인 메모 (실제 제도라 대사로 말할 때 조심할 것) — ⚠️ 전부 원문 확인 전, 기억에 기댄 것
| 내용 | 메모 |
|---|---|
| 사립학교 교장은 누가 뽑나 | 학교법인(이사회)이 임명하는 것으로 알고 있음(사립학교법). "이사회 의결" 표현은 무리 없음 |
| 교장 자격 | 일반적으로 교장 자격증이 필요하고, 공모 교장 일부 유형만 예외가 있는 것으로 알고 있음 → 34세·계약교사가 바로 교장이 되는 과정은 **대사로 자세히 설명하지 않는 게 안전**(세계관 설정으로 두기). 필요하면 원문 확인 |
| **이사장 친족의 교장 임명 제한** | 사립학교법에 이사장의 배우자·직계존비속 등은 학교장 임명에 제한(이사회 특별 의결·관할청 승인 등)이 있는 것으로 기억함 → **손녀 = 직계비속이라 해당될 수 있음.** 교감이 정체를 캐는 이유("이사장 손녀면 이 임명 문제 되는 거 아냐?")로 쓸 수 있는 강한 장치. 쓰기 전에 조문 원문 확인 필요 |
| 가족관계증명서 | 교직원 임용 서류 목록은 학교마다 다름 → 극 중 교감의 요구로만 |

## 4. 작가가 정할 것
1. 교감이 원래 교장 후보였나(그래야 시기가 커짐) — 제안: 예
2. 정체 공개 시점 — 제안: 시즌 끝(그 전엔 정우만 눈치채는 한 컷 정도)
3. 인사 예고·발표를 각각 한 화씩(9·10화) 쓸지, 한 화로 묶을지
4. 이사장 친족 임명 제한을 이야기 장치로 쓸지(쓰면 편집장이 조문 확인)
