# 설정 변경 검토 — 다해가 '서류 실수'로 교장이 됨 (2026-11-24, 사장님 생각)
사장님: "회장 손녀 이런 거 말고 누군가 서류 실수로 다해를 교장에 넣은 거야. 그럼 심플하잖아."
**결정은 작가. 아래는 이미 깔린 복선과 부딪치는 곳.**

## 이미 화면에 나간·만든 복선 (바이블 v1)
| 복선 | 화 | '서류 실수'로만 가면 |
|---|---|---|
| 이사장도 같은 빨간 만년필, 다해를 말없이 바라봄 | 5화(공개 예정) | 이유가 사라짐 → 우연으로 정리하거나 장면 의미 없어짐 |
| 교감의 가족관계증명서 독촉, 다해가 안 냄 | 6화~ | '숨길 이유'가 없어짐 → 그냥 교감 갑질로 남음 |
| '독고' 특이한 성 = 설립자 집안 | 바이블 | 설명 불필요(문제 없음) |
| 이사장 '다해를 한 번 더 봄' | 8화 계획 | 의미 없어짐 |
| 9화 끝 발령 '교장 독고다해' | 9화(완성) | 실수 설정과 잘 맞음 |

## 안
- **A. 완전 교체(진짜 서류 실수):** 가장 단순. 대신 5화 만년필·이사장 시선은 '우연'으로 닫아야 함. 실수가 드러나면 바로 물러나야 해서 2부 길이가 짧아질 위험.
- **B. (추천) 겉은 실수, 속은 아님:** 모두(교감 포함) '서류 실수'라고 믿음 → 교감은 "실수니까 곧 정정된다"며 버팀, 정정 요청 공문까지 올림 → 이상하게 정정이 안 됨(이사회가 그대로 둠) → 그동안 다해가 학교를 바꿈 → 시즌 끝에 실수가 아니었다(설립자 손녀·이사장의 뜻)가 드러나고 두 만년필 페이오프. 겉은 심플, 깔아 둔 복선은 다 살아남.
- **C. 실수였지만 그대로:** 실수가 밝혀지는데 교사들·이사회가 '이 교장 그대로'를 택함 — 감동형 엔딩. 정체 축은 버림.

## B로 가면 10화에 생기는 것
- 교감 대사 거리: "이건 서류 실수예요. 계약교사가 무슨 교장입니까. 곧 정정 공문 올 겁니다."
- 다해: "정정되기 전까지는, 제가 교장입니다." → 바로 '세상에 없는 학교 경영' 시작(실수가 바로잡히기 전에 학교를 바꾼다 = 긴박감)
- ⑦ 떡밥: 교감이 '발령 정정 요청' 공문 발송 → 답 '원안대로' → 교감 멍
