## 0. 공통 원칙 (모든 단계에 적용 — 원인을 막는 규칙)
1. 고친 뒤에는 고친 곳이 아니라 결과물 전체를, 처음부터 끝까지 실제 크기로 다시 본다.
2. 어떤 화면이든 다른 자리에 다시 쓸 때는 그 자리의 시간대·빛·인물 관계·입 상태·동작과 다시 맞춰 본다.
3. 설정값·프롬프트 지시는 '넣었다'가 아니라 결과에서 측정해 확인한 뒤에만 됐다고 말한다.
4. ID·사실·결정은 기억에서 꺼내지 않고 파일에서 찾은 값만 쓰며, 새로 들은 사실은 그 자리에서 파일에 적는다.
5. 화면마다 '누가 말하고 누가 듣는지'를 먼저 정하고, 보이는 사람과 들리는 목소리가 어긋나는 화면은 쓰지 않는다.
6. 처음 보는 사람이 설명 없이 못 알아챌 요소(속마음·시각·낯선 말·인물 소속)에는 눈이나 귀로 바로 알 수 있는 표시를 붙인다.
7. 몸이 나오는 화면은 캐릭터 시트의 옷·손·소품과 대조하고, 안 맞으면 잘라 내거나 다른 화면으로 바꾼다.
8. 꼭 들려야 할 소리는 최종 믹스에서 측정하고 사장님 청취로 확정하며, 진짜 녹음이 없으면 만들어 넣지 않는다.
9. 한 화면이 3초를 넘거나 같은 화면이 한 장면에 다시 나오면, 움직이는 관련 영상으로 바꾼다.
10. 코드 안에 들어간 글자·기호(자막 덮어쓰기, 따옴표, 역슬래시)는 만들어진 파일에서 실제 값을 열어 확인한다.

## 5. 영상 (`generate_video_batch`, Seedance 2.0)
- 설정
  ```
  {"model":"seedance_2_0","mode":"std","resolution":"480p","duration":N,"aspect_ratio":"9:16","generate_audio":false,"genre":"drama","medias":[시작 그림, audio_references(녹음 job ID 그대로 가능), image_references(인물 시트·얼굴)]}
  ```
- 초당 3크레딧. 480p로 먼저 뽑는다.
- 프롬프트 섹션 순서: GLOBAL STYLE → SCENE → CHARACTERS → LOCATION → FIRST FRAME → SHOT(초 단위) → OPTICS → CAMERA → PHYSICS → LIGHTING → AUDIO (`series/힉스필드_가이드_정리.md` 3절)
- [ ] 대사 컷: 녹음을 오디오 참조로 넣고, 이미지 참조도 꼭 함께 넣는다(오디오만 넣으면 422).
  - 한 사람씩 따로 만든다.
  - 길이 = 녹음 + 0.1초(최소 4초).
  - SHOT 마지막 구간에 "lips pressed together, mouth stays closed, listening expression"을 쓴다. 그래도 모델이 남는 시간을 말하는 입으로 채우므로, **편집에서 자르는 것이 기본**이다.
- [ ] 반응·관련 장면: 4초(12크레딧), 입 다묾(`mouth stays closed, no speaking`). 대사 내용을 보여 주는 움직임으로 만든다(밤에 하품하는 정우, 반려를 누르는 교감).
- [ ] 정지 유발어(멈춘다·굳어 있다·freeze·static·still)를 쓰지 않는다. 미세동작을 쓴다.
- [ ] 컷당 행동은 2개까지.
- [ ] 대화 컷은 측면·오버숄더로 잡고 `no one looks at the camera`를 쓴다.
- [ ] 한 컷 안에서 빛이 바뀌면 안 될 때는 "same framing, same lighting, no cut"을 쓴다.
- [ ] 요청을 보내기 직전에 그 안의 ID를 하나씩 grep으로 전체 확인한다. 미완성 요청은 함께 보내지 않는다.
- 받으면 0.25초 간격으로 펼쳐 얼굴·손·옷·빛을 시트와 대조한다. 입이 언제부터 언제까지 움직이는지도 적어 둔다.

## 6. 편집 (샌드박스, `도구/build_ep02_v5.py`를 복사해 시작 — 자막 틀 `도구/sub_v2_header.ass`, 폰트 나눔고딕·나눔명조·Black Han Sans를 ~/fonts에)
- 구조: `speak(컷, 영상, 전환 계획, 자막)`이 녹음 시각 기준으로 화면을 바꾼다. `img()`는 정지 그림 확대(글자 카드·소품에만), `clip:`은 움직이는 반응 영상이다.
- [ ] **말하는 얼굴은 목소리 끝 +0.12초에서 자른다.** 그 뒤와 입이 안 맞는 구간은 듣는 사람·관련 영상으로 덮는다.
- [ ] 한 화면은 1~3초. 말하는 도중에도 듣는 사람으로 넘어간다(소리는 그대로).
- [ ] 듣는 화면은 **말하는 동작이 없는** 화면만 쓴다(귓속말·입 가림·손짓 금지). 대사 영상을 듣는 화면으로 다시 쓸 때는 그 구간 입이 다물렸는지 프레임으로 본다.
- [ ] 다시 쓰는 화면은 새 자리의 시간대·빛과 맞는지 본다. 장면 색이 다르면 colorbalance로 맞춘다(2화 교감실: 붉은 기 빼기).
- [ ] 같은 반응 화면을 한 장면에 두 번 쓰지 않는다.
- [ ] 표·문서는 전체를 1초 안으로만 보여 주고, 대사에 맞춰 해당 칸만 큰 글씨 카드로 넘긴다.
- [ ] 글자를 화면 위에 얹을 때는 네 모서리 원근 변형으로 얹고, 원래 그림 요소를 통째로 덮는다. 실제 크기 한 프레임으로 확인한다.
- **소리**
  - [ ] 속마음: 고역·저역 자르기 + 메아리 두 겹(`aecho=0.8:0.75:60|140:0.45|0.3`).
  - [ ] 효과음은 실제 녹음 소리만 쓴다(`효과음_요청.md`). 합성 잡음·노이즈는 쓰지 않는다.
  - [ ] 대사 아래로 자동으로 줄이는 처리(덕킹)를 하되, **꼭 들려야 할 소리(결정타 효과음)는 대사 묶음에 넣어** 줄어들지 않게 한다.
  - [ ] 녹음을 자를 때는 받아쓰기 시각이 아니라 소리 크기(RMS)로 쉼을 찾아 그 안에서 자른다.
  - [ ] 음악은 칼같이 끊지 않는다(페이드). 한 장면 안에서 같은 곡을 다시 시작하지 않는다.
  - [ ] 최종 −14 LUFS, 트루피크 −1 dB 아래(loudnorm + `alimiter=limit=0.84:level=false` — level을 끄지 않으면 다시 0 dB까지 키움). **편집본마다** ebur128로 재어 생성로그에 적는다.
- **끝 카드:** 3초, "교사X N+1화 ○월 ○일(○) 저녁 6시".
- **올리기:** `media_upload`로 주소를 받고 → 같은 명령에서 curl PUT(`-H "Content-Type: …" -H "If-None-Match: *"`) → 200이면 `media_confirm`.
  - 서명 주소는 파일에 저장해 그대로 쓴다(옮겨 적다 틀리면 400).
- 끝나면 생성로그에 media ID를 적는다. 오디오 파일은 git에 올리지 않는다.

- 설명란: 첫 줄 훅 → 이전 화 링크 → 다음 화 날짜 → AI 안내 → 효과음 표기 → 해시태그.
- 고정 댓글은 교사에게 묻는 질문으로 끝낸다.
- 커버 3종(`도구/cover_mk.py`): 왼쪽 위 "교사X N화", 노란 큰 글씨 2줄(한 줄 12~13자 안), 빨간 상황 띠, @twistbite_drama. 폰 크기로 글자가 화면 안에 들어오는지 본다.
- 예약: 매주 수 18:00 KST. 지니에게 넘기는 지시는 맨 위에 둔다.
- 음원 출처는 사장님께 묻지 않는다(사장님이 관리, `음악/README.md`·`효과음_요청.md`가 기준).
