## 2. 관문 체크리스트 (다음 단계로 넘어가기 전에 반드시)

### 관문 A — 대본
- [ ] 사장님이 말하지 않은 설정을 넣지 않았다(필요하면 "제안"으로 따로).
- [ ] 줄마다 **시각·장소·말하는 사람 → 듣는 사람**을 처음부터 끝까지 다시 확인했다.
- [ ] 줄마다 "앞 3초만 본 시청자가 알아듣나?"를 확인했다(나만 아는 맥락 금지).
- [ ] 확정 대사는 바꾸지 않는다. 다시 녹음할 때도 글자 그대로(소리 나는 대로 적기만 허용).

### 관문 B — 녹음·생성 요청
- [ ] 요청에 든 **ID를 하나씩 grep으로 전체 확인**했다(짐작·자리표시 금지).
- [ ] 다해 지시어 = 담담·건조·짧게, **미소(smile)·친절 금지**. 새 녹음은 1화 다해와 이어 듣는다.
- [ ] 받은 녹음: 받아쓰기로 한 글자씩 대조(반복·뭉개짐 → 다시), **줄마다 LUFS 재서 앞뒤 대사와 2dB 안**.
- [ ] 비용은 승인 파일에 먼저, 실행 뒤 장부에.

### 관문 C — 그림
- [ ] 컷마다 **샷 크기·앵글·카메라 움직임 표**를 먼저 만들었다(매뉴얼 4절).
- [ ] 말하는 사람마다 **그 얼굴이 보이는 시작 그림**이 있다.
- [ ] **인물별 얼굴 대조판**(모든 컷 얼굴 + 시트)을 만들어 나이·머리·안경을 비교했다. 다르면 영상 전에 다시 그린다.
- [ ] 손·팔 개수, 빈 말풍선, 글자 칸을 봤다.
- [ ] 글자를 얹을 그림은 물건(도장·라벨·종이·화면)을 **픽셀로 재서** 가운데·기울기·크기를 적어 둔다.

### 관문 D — 영상
- [ ] 클립 소리와 원래 녹음을 맞춰 **녹음 위치(초)**를 쟀다. 맞춤 점수가 낮은 클립은 입 모양 프레임을 직접 본다.
- [ ] 대사 구간마다 입이 움직이는지, 대사 뒤 입이 닫히는지 프레임으로 봤다. 말을 늦게 시작하면 그만큼 자르거나 Seedance로 다시.
- [ ] 반응 컷은 0.5초 간격으로 보고, **말하는 동작**(귓속말·손짓)이 있으면 다른 사람 대사 위에 두지 않는다.
- [ ] 반응·인서트 컷의 **시간대·조명**이 장면과 같다.

### 관문 E — 편집 뒤 글자 전수 확인 (사장님 11/18 "매번 텍스트 문제야")
- [ ] 글자가 나오는 **모든 컷의 시작·중간·끝 프레임**을 크게 뽑았다(훅 제목·자막·태그·시간 글자·그림 속 글자·엔딩).
- [ ] 세 가지를 봤다: **잘림**(화면 가장자리·도장 테두리) / **겹침**(제목·자막·태그·그림 속 글자·얼굴·입) / **기울기**(물건과 같은 각도).
- [ ] 확대가 계속 커지는 화면에 글자가 있으면 끝 프레임에서 잘리는지 봤다(글자 있는 화면 확대는 1.1~1.2 고정).
- [ ] 그림을 고쳤으면 **완성 영상의 그 프레임**에서 고쳐졌는지 봤다(그림 파일만 보고 끝내지 않음).

### 관문 F — 보고 전
- [ ] 바꾼 것은 **완성 영상에서 재서** 확인했다: 글자 = 프레임, 소리 = 그 시각 LUFS, 전체 = LUFS·최고점, 길이 = 영상·소리 길이 차 0.05초 이하.
- [ ] 마지막 대사 뒤 말 없는 구간 5초 이하, 자막 겹침 0건.
- [ ] 직접 듣지 못한 소리는 "확인했다"고 쓰지 않고 수치만 적고 사장님 청취를 부탁한다.
- [ ] Gemini 지적은 **재서 맞는지 먼저** 확인하고, 맞음·틀림·극 중 설정으로 나눠 보고한다.

## 3. 사람 눈 대신 코드로 막을 것 (만들면 좋은 도구 — 사장님 승인 후)
