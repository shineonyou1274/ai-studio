# 편집 메모 — 공간음(Convolution Reverb)

2026-11-13 메모 (사장님 "필요할 때 쓰게 메모해 두자"). 아직 적용 안 함, 쓸 때 사장님 확인.

## 무슨 말인가
- **공간음**: 같은 목소리도 방이 다르면 다르게 들린다. 작은 교감실, 넓은 교무실, 복도, 텅 빈 교실은 각자 울림이 다르다.
- **리버브(reverb)**: 그 울림을 소리에 입히는 효과.
- **컨볼루션(Convolution) 리버브**: 실제 공간에서 '딱' 소리(박수, 풍선 터뜨리기)를 녹음해 둔 짧은 파일(**IR, 임펄스 응답**)을 목소리에 겹쳐서, 그 공간에서 말한 것처럼 만드는 방식. 기계식 리버브보다 진짜 방 같다.

## 왜 우리에게 필요한가
- 우리 녹음(ElevenLabs)은 **스튜디오처럼 너무 깨끗하다(dry)**. 그래서 화면 속 교무실과 따로 노는 '붙여 넣은 소리'처럼 들릴 수 있다.
- 공간 울림을 아주 조금 입히면 대사가 장면 속에 앉는다.

## 교사X에서 쓸 곳 (후보)
| 장면 | 공간 | 느낌 |
|---|---|---|
| 교무실 대화 | 중간 크기 사무실 | 아주 약하게(거의 안 들릴 만큼) |
| 교감실(2화 S3) | 작은 방, 책장·소파 | 짧고 따뜻한 울림 → 교무실과 다른 방이라는 게 귀로 느껴짐 |
| 복도·교감 외침 | 긴 복도 | 길게 울림 |
| 운동장 | 바깥 | 울림 거의 없음(지금처럼) |
| 속마음 | 현실 공간 아님 | 지금 방식(고역·저역 자르고 메아리) 유지 — 공간 리버브 쓰지 않음 |
| 문 밖에서 들리는 소리 | 문 너머 | 리버브 + 고음 깎기(먹먹하게) |

## 어떻게 (샌드박스 ffmpeg)
- `afir` 필터: 목소리 + IR 파일 → 공간음. 원음(dry)과 울린 소리(wet)를 섞되 **wet은 10~20%부터** 시작.
- 예: `ffmpeg -i line.wav -i room_ir.wav -filter_complex "[0][1]afir=dry=10:wet=2[a]" -map "[a]" out.wav` (수치는 귀로 맞춤)
- IR 파일 구하기: 무료 IR 모음(예: OpenAIR 같은 연구용 라이브러리)에서 **작은 사무실·방·복도** IR. **쓰기 전 라이선스(상업 이용) 확인 필수** — 확인 안 되면 쓰지 않음. 효과음처럼 `효과음_요청.md` 흐름으로 지니·사장님이 골라 줘도 됨.
- IR이 없을 때 대안: ffmpeg `aecho`로 짧은 방 울림 흉내(덜 자연스러움).

## 주의
- 편집장(Claude)은 소리를 못 들음 → **반드시 사장님 청취로 확인**. 1화 합성 효과음이 어색했던 실수(실수표) 기억.
- 과하면 '목욕탕 소리'가 됨. 들릴 듯 말 듯이 기본.
- 대사 영상 소리를 끄고 녹음을 얹는 방식이라, 같은 장면 대사는 **모두 같은 공간음**으로 맞춰야 튀지 않음.
- 처음 쓸 때는 한 장면(예: 2화 교감실)만 '있음/없음' 두 판으로 만들어 사장님이 비교.
