**쓰는 법**
1. 편집장(Claude)이 필요한 소리를 아래 "요청" 표에 적고 커밋한다(장면·길이·느낌·쓸 곳).
2. 지니(다른 AI) 또는 사장님이 골라서 대화창에 파일을 올리고, "받음" 칸에 출처를 적는다(무료 상업 이용 가능한 곳: Pixabay, Freesound CC0, ElevenLabs 생성 등).
3. 편집장이 Higgsfield에 올리고 media id를 "받은 소리" 표에 적는다. **음원 파일 자체는 저장소에 넣지 않는다**(남의 음원).
4. 코드로 만든 합성음은 임시용. 사장님 피드백(11/12): 종·셔터·문·잡음이 어색 → 실제 녹음 소리를 우선.
