# AI 배우 연기 지시서 | 제작팀 컷 카드

용도: 연기가 중요한 컷을 만들기 전 작가·연출·음향·편집이 같은 순간을 상상하도록 작성한다. 기존 승인 대사·인물·의상·목소리는 바꾸지 않는다.

## 참고 영상에서 배울 점
- [00:35 지시의 세 층](https://youtu.be/gHrvN9jjf3o?t=35): 장소·인물 → 카메라가 언제 누구를 보는지 → 배우가 무엇을 참으며 상대에게 무엇을 하려는지. 장소와 렌즈를 세밀하게 써도 연기 지시가 비어 있으면 표정만 고정된다.
- [01:33 감정이 바뀌는 과정](https://youtu.be/gHrvN9jjf3o?t=93): 화내다 갑자기 울리지 말 것. 따진다 → 대답을 듣고 급히 숨을 들이쉰다 → 다음 문장을 낮춰 말한다. 필요하면 ‘눈가는 젖지만 눈물은 떨어지지 않는다’처럼 하지 않을 행동도 쓴다.
- [02:52 대화 타이밍](https://youtu.be/gHrvN9jjf3o?t=172): 상대가 말을 끝냈다는 이유만으로 대답을 시작하지 않는다. 부정하려는 사람은 말을 끊을 수 있고, 처음 알게 된 사람은 입을 열었다가 멎을 수 있다. 영상의 0.1초 선행·0.2초 겹침은 특정 예시이지 기본 설정이 아니다. 머뭇거림은 꺼내기 어려운 단어 한 곳에만 둔다.
- [04:17 슬픔을 세 갈래로](https://youtu.be/gHrvN9jjf3o?t=257): 저절로 새는 반응 / 감추려는 행동 / 그러면서 상대한테 해주려는 일. 예: 목이 메지만 → 고개를 돌려 숨을 고르고 → 상대의 옷깃을 여며준다. 마지막 행동이 있어야 ‘슬픈 표정 연습’이 아니라 두 사람의 장면이 된다.
- [05:29 관찰과 수정](https://youtu.be/gHrvN9jjf3o?t=329): 먼저 실제 사람의 움직임을 보고, 어느 말에서 어느 부위가 얼마나 움직이는지 기록한다. 결과가 틀리면 장소·카메라·연기 중 원인이 있는 층만 수정한다.

## 작업할 때 복사할 빈 카드
```
컷 번호 / 길이 / 승인된 대사(또는 무언):
장소·인물 고정값 / 어떤 구도로 무엇을 보여줄지:
상대에게 하려는 일 / 들키고 싶지 않은 것:
반응을 일으키는 상대의 정확한 말·행동:
처음 행동 → 무심코 새는 반응 → 다시 감추거나 선택하는 행동:
대사 박자: 어느 단어 전후에 쉬거나 겹치는가? 이유는?
끝까지 하지 않을 행동 하나:
합격 기준: __초의 __이 보이거나 들리면 통과. 실패 시 __만 수정.
```

## 한입극장 적용 예시 | 새 연출 제안, 기존 영상 분석 아님
마녀의 승인 문구 ‘내 것이 될 수 없다면 / 아무도 가질 수 없어.’를 그대로 사용한다. 첫 문장 목적은 협박이 아니라 엘리안이 마음을 바꿀 기회를 한 번 더 주는 것. 상대가 시선을 거두는 순간 첫 문장 뒤에 남겨 둔 숨을 내쉰다. 잠깐 대답을 기다린 뒤 둘째 문장은 첫 문장보다 작고 단정하게 끝낸다. 고함·웃음·눈물을 더하지 않는다. 관객이 ‘기다렸다가 결심했다’고 읽으면 통과. 단순 낭독처럼 들리면 대사를 바꾸기 전에 쉼의 위치부터 확인한다.

## 인계·검수 순서 | 우리 팀 제안
작가는 상대에게 하려는 일을 동사로 적는다. 연출은 전환의 계기와 전후 행동을 정한다. 촬영은 그 반응이 보이는 구도를 고른다. 음향은 숨·겹침·멈춤의 위치를 표시한다. 편집은 듣는 사람의 반응을 잘라내지 않는다. 검수자는 실제 MP4에서 ‘무슨 말이나 행동 뒤 / 몇 초에 / 무엇이 변했나’를 답하고, 확인하지 못한 소리는 미확인으로 둔다. 장면 전부를 재생성하지 않는다.
