# 공정 3. 콘티 (콘티 작가)

## 1. 목적
영상 전체의 흐름을 컷 단위로 나누고(storyboard-v1), 핵심 컷은 샷 단위로 잘게 나눠(storyboard-v2) 프롬프트 담당이 그대로 옮길 수 있게 합니다.

## 2. 시작 조건
- `02_캐릭터/lock-spec.md`가 완료 기준을 채웠습니다.

## 3. 입력
- `01_기획/brief.md`
- `02_캐릭터/lock-spec.md`
- 스킬: `anthropic-skills:storyboard-v1`, `anthropic-skills:storyboard-v2`

## 4. 단계
1. 기획서의 흐름(시작·전개·결말)과 길이를 읽습니다.
2. storyboard-v1 형식으로 전체 콘티를 씁니다. 컷마다 행동(ACTION), 카메라(CAMERA), 대사(DIALOGUE)를 적습니다.
3. 인물 묘사는 LOCK SPEC의 문장을 그대로 붙여 넣습니다. 새로 묘사하지 않습니다.
4. 이야기에서 가장 중요한 컷 1~2개를 고릅니다.
5. 고른 컷마다 storyboard-v2 형식으로 샷 분해를 씁니다(샷별 시작·끝 프레임, 카메라 움직임, 효과음).
6. 콘티 시트 이미지는 만들지 않고, 생성 스펙만 파일에 남깁니다.

## 5. 결과물
- `03_콘티/storyboard-v1.prompt.md` — 전체 콘티와 시트 생성 스펙
- `03_콘티/storyboard-v2-cut<번호>.prompt.md` — 핵심 컷별 샷 분해

## 6. 완료 기준
- 컷 길이를 모두 더하면 기획서의 전체 길이와 같습니다.
- 모든 컷의 인물 묘사가 LOCK SPEC과 글자 그대로 같습니다.
- 핵심 컷이 1개 이상 샷 분해되어 있습니다.

## 7. 예외
- 기획서의 길이 안에 흐름을 담을 수 없으면, 줄일 부분을 제안하고 편집장에게 알립니다.
