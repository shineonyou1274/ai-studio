# 공정 4. 프롬프트 (프롬프트 담당)

## 1. 목적
앞 공정의 결과를 영상 생성 모델에 바로 넣을 수 있는 지시문(프롬프트)으로 바꿉니다. 컷이 바뀌어도 인물, 공간, 시간이 이어지게 합니다.

## 2. 시작 조건
- `03_콘티/`의 결과물이 완료 기준을 채웠습니다.

## 3. 입력
- `01_기획/brief.md`, `02_캐릭터/lock-spec.md`, `03_콘티/*.prompt.md`
- 스킬: 이야기형은 `anthropic-skills:seedance-continuity-builder`, 광고형은 `anthropic-skills:ad-motion-prompt`

## 4. 단계
1. 시리즈 회차는 `seedance-continuity-builder`를 씁니다. 광고형 단편일 때만 `ad-motion-prompt`를 씁니다.
2. 스킬이 요구하는 연속성 기준표(Continuity Bible)를 LOCK SPEC과 콘티에서 그대로 옮겨 만듭니다.
3. 기획서의 `생성 단위 나누기`에 따라 15초 이하 단위로 나누어 프롬프트를 씁니다. 화면 비율은 가로 16:9이고, 인물은 화면 가운데 근처에 둡니다. 화면 글은 프롬프트에 넣지 않고(글자 없는 화면) 촬영 담당이 코드로 얹도록 따로 적습니다.
4. 참조 이미지 표기 방식(스킬의 REFERENCE MODE)은 Higgsfield 도구로 이미지를 넘기는 방식에 맞춥니다. 확실하지 않으면 자연어 방식(MODE A)을 쓰고, 그 사실을 파일에 적습니다.
5. 광고형이면 스킬의 `scripts/check_prompt.py`로 글자 수를 잽니다.

## 5. 결과물
- `04_프롬프트/seedance-bundle.md` — 기준표와 전체 프롬프트 묶음(한글·영문 블록)
- `04_프롬프트/prompt-cut<번호>.txt` — 생성 한 번에 그대로 넣을 영문 프롬프트

## 6. 완료 기준
- 모든 생성 단위가 15초 이하입니다.
- 각 단위의 길이를 더하면 기획서의 전체 길이와 같습니다.
- 모든 단위에 같은 인물 묘사와 네거티브(나오면 안 되는 것) 목록이 들어 있습니다.

## 7. 예외
- 콘티의 컷을 프롬프트로 옮길 수 없는 이유(예: 모델이 못 그리는 동작)가 있으면, 대체 동작을 제안하고 편집장에게 알립니다.
