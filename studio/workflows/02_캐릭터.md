# 공정 2. 캐릭터 고정 (캐릭터 담당)

## 1. 목적
확정 배역 이미지를 기준으로 이 회차에 나오는 인물의 얼굴, 몸, 옷, 색을 글로 고정(LOCK SPEC, 바꾸지 않을 설정)해서, 이후 모든 컷과 모든 회차에서 같은 사람으로 보이게 합니다.

## 2. 시작 조건
- `01_기획/brief.md`와 `script.md`가 완료 기준을 채웠습니다.

## 3. 입력
- `01_기획/brief.md`의 `등장 배역`, `플랫폼·비율·길이`
- 확정 배역 이미지와 설명: `series/README.md`에 적힌 cast 폴더 (job ID 포함)
- 시리즈에 이미 만든 LOCK SPEC이 있으면 `series/<시리즈>/lock-spec.md` (있으면 그대로 씁니다)
- 스킬: `anthropic-skills:master-sheet-v2` (기본), `anthropic-skills:master-sheet-v1` (의상·소품·색이 중요할 때)

## 4. 단계
1. 기획서의 등장 배역을 한 명씩 확인합니다.
2. 확정 배역은 cast 이미지를 직접 보고, 이미지에 보이는 그대로 LOCK SPEC을 씁니다. 시리즈 LOCK SPEC이 이미 있으면 새로 쓰지 않고 그대로 가져옵니다.
3. 레퍼런스 시트가 아직 없는 확정 배역은 master-sheet-v2 형식으로 시트 생성 스펙을 씁니다. 이때 cast 이미지를 참조 이미지로 지정합니다.
4. 미확정 배역(예: 고양이들)은 글로 된 오디션 후보 2~3개와 저화질 오디션 생성 스펙을 씁니다.
5. 의상이 여러 벌이거나 소품·색이 이야기에 중요하면 master-sheet-v1 형식으로 한 번 더 씁니다.
6. 스킬이 정한 LOCK SPEC 블록을 인물마다 채우고, 한 파일에 모읍니다.
7. 이미지 생성은 하지 않습니다. 생성은 공정 5에서 승인을 받은 뒤 합니다.

## 5. 결과물
- `02_캐릭터/lock-spec.md` — 모든 인물의 LOCK SPEC 블록
- `02_캐릭터/sheet-<배역 영문 이름>.prompt.md` — 배역별 시트 이미지 생성 스펙
- `02_캐릭터/audition-<배역>.md` — 미확정 배역의 오디션 후보(있을 때만)

## 6. 완료 기준
- 기획서의 확정 배역이 빠짐없이 LOCK SPEC에 있고, 묘사가 cast 이미지와 어긋나지 않습니다.
- 기획서에 없는 인물이 추가되지 않았습니다.
- 비율이 가로 16:9이고, 인물이 화면 가운데 근처에 있도록 지시되어 있습니다.
- 각 생성 스펙에 모델 이름, 비율, 프롬프트 전문이 있습니다.

## 7. 예외
- 기획서·원고의 인물 설명과 cast 이미지가 서로 부딪치면(예: 멘토의 나이) 고치지 말고 `원작자가 정할 것`으로 편집장에게 알립니다.
- 스킬이 바로 이미지를 만들라고 해도 만들지 않습니다. 이 공정에서는 크레딧이 드는 도구를 쓸 수 없습니다.
