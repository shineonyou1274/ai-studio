# 공정 6. 편집·배급 (편집·배급 담당)

## 1. 목적
완성 영상에 음원과 자막을 붙여 유튜브 본편(가로 16:9)과 쇼츠(세로 9:16)를 만들고, 업로드 묶음(제목, 설명란, 썸네일 프레임 등)을 써서 "게시 대기" 목록에 올립니다. 게시는 사용자가 합니다.

## 2. 시작 조건
- `05_촬영/final/`에 승인받은 고화질 영상이 있습니다.

## 3. 입력
- `05_촬영/final/*`, `01_기획/brief.md`, `01_기획/script.md`
- 사용자가 준 음원(있을 때만)
- 업로드 규칙: `PLAYBOOK.md` 4절
- 조사 자료: `series/README.md`에 적힌 유튜브 조사 자료(제목·썸네일·쇼츠)

## 4. 단계
1. 컷 영상이 여러 개면 ffmpeg로 이어 붙여 본편을 만듭니다.
2. 사용자 음원이 있으면 붙이고, 없으면 영상 그대로 둡니다.
3. 자막이 필요하면 코드로 얹습니다(촬영 공정에서 이미 얹었으면 건너뜁니다).
4. 본편에서 썸네일로 쓸 프레임(인물 표정 + 회차 표시)의 시각을 고릅니다.
5. 기획서의 `단 하나의 순간`이 담긴 구간(40~60초)을 9:16으로 가운데를 잘라 쇼츠를 만듭니다. 첫 1~2초에 가장 센 장면이 오게 합니다. 인물이 잘리는 컷이 있으면 자르는 위치를 옮기고 기록합니다.
6. `06_배급/youtube.md`를 아래 제목 순서대로 씁니다.
   `본편 제목`, `본편 설명란`, `썸네일 프레임 시각`, `쇼츠 제목·구간`, `해시태그`, `고정 댓글`, `AI 생성 표시`, `업로드 전 확인할 것`
7. 편집장에게 "게시 대기"로 표시해 달라고 보고합니다.

## 5. 결과물
- `06_배급/final.mp4` — 본편(16:9)
- `06_배급/shorts-<번호>.mp4` — 쇼츠(9:16)
- `06_배급/youtube.md` — 업로드 묶음

## 6. 완료 기준
- 본편 길이가 기획서의 전체 길이와 1초 이상 차이 나지 않습니다.
- 쇼츠가 60초 이하이고, 인물이 화면 밖으로 잘린 구간이 없습니다.
- 설명란에 가상 인물·창작물 안내 문구가 있고, `AI 생성 표시`가 "예"로 적혀 있습니다.
- `project.md`의 상태가 "게시 대기"입니다.

## 7. 예외
- 음원의 저작권을 확인할 수 없으면 영상은 만들되 커밋하지 않고, 그 사실을 `youtube.md` 맨 위에 적습니다.
- 어떤 경우에도 외부 서비스에 직접 올리지 않습니다.
