# 공정 5. 촬영 (촬영 담당) — 승인 필요

## 1. 목적
승인받은 범위 안에서만 Higgsfield로 캐릭터 시트와 영상을 만듭니다. 싼 시안을 먼저 만들고, 확인받은 뒤 고화질을 만듭니다.

## 2. 시작 조건
- `04_프롬프트/`의 결과물이 완료 기준을 채웠습니다.
- 승인 요청을 올리기 전에는 어떤 생성 도구도 부르지 않습니다.

## 3. 입력
- `02_캐릭터/sheet-*.prompt.md`, `04_프롬프트/prompt-cut*.txt`
- 스킬: `anthropic-skills:ad-motion-make`

## 4. 단계
1. `balance`로 남은 크레딧을 봅니다.
2. `models_explore`로 쓸 모델을 확인하고, `get_cost: true`로 캐릭터 시트와 480p 시안의 비용을 잽니다.
3. 비율은 가로 16:9가 기본입니다. `05_촬영/approvals/01-draft.json`에 승인 요청을 씁니다(아래 형식). 그리고 멈춥니다.
4. 승인되면 캐릭터 시트를 먼저 만들고, 그 시트를 참조 이미지로 넣어 480p 시안을 만듭니다.
5. 시안의 프레임을 뽑아(`ad-motion-make/scripts/frames.sh`) 직접 보고, 인물이 바뀌었거나 한글이 깨졌는지 확인합니다.
6. `05_촬영/approvals/02-final.json`에 고화질 승인 요청을 쓰고 멈춥니다.
7. 승인되면 고화질을 만들고, 한글이 깨졌으면 글자 없는 영상에 코드로 자막을 얹습니다(`ad-motion-make/scripts/overlay.mjs`).

승인 요청 형식:
```json
{
  "id": "01-draft",
  "status": "pending",
  "items": [
    {"what": "캐릭터 시트 1장 (주인공)", "model": "확인한 모델 이름", "spec": "비율·해상도", "cost": 0}
  ],
  "total_cost": 0,
  "balance": 0,
  "requested_at": "ISO 시각"
}
```

## 5. 결과물
- `05_촬영/approvals/*.json` — 승인 요청과 결과
- `05_촬영/sheets/`, `05_촬영/draft/`, `05_촬영/final/` — 만든 이미지와 영상
- `05_촬영/jobs.md` — job ID, 모델, 쓴 크레딧 기록

## 6. 완료 기준
- 만든 모든 결과물에 대응하는 승인 파일이 있고, 그 상태가 `approved`입니다.
- 승인된 비용보다 많이 쓰지 않았습니다.
- 시안을 확인한 기록이 있고, 그 뒤에 고화질을 만들었습니다.

## 7. 예외
- 크레딧이 모자라면 생성하지 않고, 낮은 해상도나 짧은 길이를 승인 요청에 대안으로 적습니다.
- 생성이 실패하면 같은 요청을 반복하지 않고, 실패 내용을 `jobs.md`에 적은 뒤 편집장에게 알립니다.
- 반려(`rejected`)되면 이유를 기록하고 멈춥니다.
