# AI 영상 제작 스튜디오 (`studio/`)

유튜브 시리즈의 한 화를 맡기면 직원 7명(서브에이전트)이 기획 → 검토 → 캐릭터 → 콘티 → 프롬프트 → 촬영 → 편집·배급 순서로 작업합니다. 크레딧이 드는 생성은 사용자가 승인해야 시작합니다.

**처음이라면 `PLAYBOOK.md`부터 읽으십시오.** 한 화를 만들어 올리기까지의 순서가 한 장에 있습니다.

| 경로 | 내용 |
|---|---|
| `PLAYBOOK.md` | 유튜브 시리즈 제작 플레이북(한 화의 순서, 확인 시점, 업로드 규칙) |
| `CLAUDE.md` | 편집장(메인 세션) 운영 규칙 |
| `.claude/agents/` | 직원 7명의 설정 |
| `workflows/` | 공정별 업무 파일(목적, 시작 조건, 입력, 단계, 결과물, 완료 기준, 예외) |
| `series/` | 시리즈 목록, 시리즈별 작가 규칙 |
| `projects/` | 회차마다 하나씩 만드는 작업 폴더 (`_template.project.md` 참고) |
| `../ai-office.html` | 3D 사무실 화면 시안 (3단계에서 실제 신호로 움직이게 고칠 예정) |
| `../docs/`, `../영상스튜디오_작업지시서.md` | 작업 지시서와 단계별 보고 |

Claude Code는 이 `studio/` 폴더를 작업 폴더로 삼아 실행해야 위 설정이 적용됩니다.
